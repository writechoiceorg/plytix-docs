### Short Text

The Short Text attribute is perfect for names, identifiers with letters, and other short values of text. It is the perfect option when you need to see the entire value of this attribute in the Product Overview table. 

 

[![attributes-short_text](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Attribute%20types/attributes-short_text.png?width=670&height=355&name=attributes-short_text.png)](https://help.plytix.com/hubfs/Help%20center/Product%20Editing/Edit%20Product%20Attributes/Short%20Text.png)

#### Available filters

- is defined
- isn't defined
- contains
- doesn't contain
- equal to
- not equal to

💡 When using a Short Text attribute, you will see the entire value of this attribute in the Product Overview table so make sure you keep it short to avoid crowding your table, or set a character limit.

The system attribute** SKU** is a short text attribute. If you ever need to filter out a list of SKUs you can simply apply a filter saying "SKU contains any of" and insert these SKUs (this can even be done via copy and paste from a file). This filtering option allows you to filter out up to 100 SKUs at a time. 

![overview-filter_sku](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Attribute%20types/overview-filter_sku.png?width=670&height=357&name=overview-filter_sku.png)

💡 Short Text Attributes also allow you to filter on character count. This filter conditions ensures you to comply with any SEO standards by identifying content that has either too many or too little characters.

To filter on character count simply: 
1. Select a Short Text Attribute in the "**Filter section**" of the "**Product Overview**"
2. Enable the box "**Character count**" 
3. Choose the condition you wish to filter on 
4. Type in the character count
5. Click '**Apply filter**'

![overview-filter-character_count](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Attribute%20types/overview-filter-character_count.png?width=670&height=357&name=overview-filter-character_count.png)

If you want to limit the amount of characters in a short text attribute, check the box in the "Settings" section when you create it, then type the number of characters for your limit.

![Short text](https://help.plytix.com/hs-fs/hubfs/Help%20center/Getting%20Started/Attribute%20Types/Short%20text.png?width=670&height=415&name=Short%20text.png)

In the event you try to add a value over the limit, the attribute will turn red and tell you how many characters are over the limit.

![attribute-short_text-character_limits](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Attribute%20types/attribute-short_text-character_limits.png?width=670&height=357&name=attribute-short_text-character_limits.png)

### Paragraph

Used for longer pieces of plain text, eg. description, instructions and warranty content. 

[![attribute-paragraph-01](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Attribute%20types/attribute-paragraph-01.png?width=670&height=358&name=attribute-paragraph-01.png)](https://help.plytix.com/hubfs/Help%20center/To%20Be%20Organize/Paragraph.png)

ℹ️  When viewing this attribute in the Product Overview table, you will only be able to view a summary that contains the first two lines.

#### Available filters

- is defined
- isn't defined
- contains
- doesn't contain
- equal to
- not equal to

💡 Just as described above for the short text attribute, paragraph attributes can also be filtered on character count conditions. 

To add a character limit to a Paragraph attribute, check the box under settings and type the maximum number of character you want to allow.

![attribute-paragraph](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Attribute%20types/attribute-paragraph.png?width=670&height=357&name=attribute-paragraph.png)

Trying to add a value over the limit will cause the attribute to turn red and display how many characters are over the limit.

![attribute-paragraph-limit](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Attribute%20types/attribute-paragraph-limit.png?width=670&height=357&name=attribute-paragraph-limit.png)

### Integer Number

A numerical input that only allows for whole numbers. Useable for quantities, numerical identifiers, weight in grams, volume in ml/oz.

![attribute-integer_number](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Attribute%20types/attribute-integer_number.png?width=670&height=357&name=attribute-integer_number.png)

 

⚠️  If you input anything other than an integer, you will get an error message. You can add up to **16 characters** in an integer attribute. 

#### Available filters

- is defined
- isn't defined
- equal to
- not equal to
- greater than
- greater than or equal to
- less than
- less than or equal to

### **Dropdown**

For a set of options where only one option can apply at a time, i.e a color or size.

[![attribute-dropdown](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Attribute%20types/attribute-dropdown.png?width=670&height=357&name=attribute-dropdown.png)](https://help.plytix.com/hubfs/Help%20center/To%20Be%20Organize/Dropdown.png)

ℹ️ When editing a dropdown attribute, you can choose to 'Restrict' adding new options on import so that the value for this attribute can only be one of the options you have already added. This can help avoid new options being added accidentally in the case of misspellings or capitalization changes. [Learn more about restricting the options for a dropdown attribute here.](https://help.plytix.com/en/restricting-options-of-dropdown-or-multiselect-attributes)

⚠️  Dropdown Attributes are limited to 1000 options. 

#### Available filters

- is defined
- isn't defined
- equal to
- not equal to
- contains any of
- doesn't contain any of

### Multiselect

For a set of options when multiple options can apply simultaneously, i.e. color combinations or available retail outlets (web shop, retail store...)

[![attribute-multiselect](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Attribute%20types/attribute-multiselect.png?width=670&height=357&name=attribute-multiselect.png)](https://help.plytix.com/hubfs/Screenshot%202020-12-30%20at%2017.30.53.png)

ℹ️ When editing a multiselect attribute, you can choose to 'Restrict' adding new options on import so that the value for this attribute can only be one of the options you have already added. This can help avoid new options being added accidentally in the case of misspellings or capitalization changes. [Learn more about restricting the options for a multiselect attribute here.](https://help.plytix.com/en/restricting-options-of-dropdown-or-multiselect-attributes)

⚠️  Multi-Select attributes are limited to 1000 options. 

#### Available filters

- is defined
- isn't defined
- contains any of
- doesn't contain of

### Date

When you need a uniform way to tell the date. Some examples are launch dates, end of life dates, created date, modified date etc.

 

[![attribute-multiselect (2)](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Attribute%20types/attribute-multiselect%20(2).png?width=670&height=356&name=attribute-multiselect%20(2).png)](https://help.plytix.com/hubfs/Date-attribute.png)

ℹ️  Check out how to [configure the Date attribute](https://help.plytix.com/configuring-the-date-attribute). 

#### Available filters

- is defined
- isn't defined
- Custom date
- Relative date

When filtering by **Custom date,** you will find the following options to filter by:
- equal to
- after
- on or after
- before
- on or before

When filtering by **Relative date**, you will be asked to define the number of days by which you want to filter through; e.g. "Last 7 days"

💡 When filtering under "Created Date" or "Modified Date" you are also able to indicate a specific time to identify when certain changes were made.
