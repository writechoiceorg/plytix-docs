# Viewing Export Logs

## How to track what product data has been exported from the Product Overview table

In Plytix, you can export products in CSV, XLSX, and PDF format from the product overview. 

Regardless of how the file is delivered, you will see a summary of these exports in the Export Logs where you can download the original file. 

💡 If an export file is small enough, it will automatically download in your browser. If the file is large or contains complex information, it will download as a ZIP file, or you'll receive an email once it is finished.

### How to access Export Logs:

1. Click **'Exports'** in the navigation menu on the left side.

![Export 1](https://help.plytix.com/hs-fs/hubfs/Help%20center/Sharing%20Your%20Data/Viewing%20Export%20Logs/New%20design%202026/Export%201.jpg?width=670&height=329&name=Export%201.jpg)

2. Exports are listed in order by date from newest to most recent.

---

###
How to download files:

1. At the end of the export row, click the** 'Download'** icon.
2. The file will automatically download in the browser.

![Export log - download](https://help.plytix.com/hs-fs/hubfs/Help%20center/Sharing%20Your%20Data/Viewing%20Export%20Logs/New%20design%202026/Export%20log%20-%20download.jpg?width=670&height=73&name=Export%20log%20-%20download.jpg)

ℹ️ Download links to your export file will be available for 14 days after the export is done. After this time, the information in the export log will disappear.

###
How to read the table

![How to read the table - Export log](https://help.plytix.com/hs-fs/hubfs/Help%20center/Sharing%20Your%20Data/Viewing%20Export%20Logs/New%20design%202026/How%20to%20read%20the%20table%20-%20Export%20log.jpg?width=670&height=82&name=How%20to%20read%20the%20table%20-%20Export%20log.jpg)

ℹ️ The Export Logs table displays 25 records at a time. 

**
EXPORT DATE**

This is the date when the file was dowloaded.

**USER**

This is the person who downloaded the file.

**FILE NAME**

The name of the file downloaded. 

**FILE TYPE**

There are four file types that appear here: CSV and XLSX are spreadsheets, PDFs are documents and ZIP files are those that were compressed for faster download.

Only files exported from the Product Overview table are shown here. Exports from Brand Portals and Channels do not appear here. 

**STATUS**

You will see three status options here: "Finished" (download is finished), "Failed" (download failed for some reason), or "Processing" (download is in progress).

**EXPIRES AT**

Links to files are valid for 14 days after the export is done. After that time, the download link will disappear from the table and will no longer be accessible.
