# Managing Views

## How to create, manage, and delete views from the settings tab

Views let you quickly switch between different sets of information. By creating Views, you can choose the attribute columns you want to see in the Product Overview table, along with filters, sorting, Product Family, and hierarchy levels, and save them for future use. You can work with Views from the [Product Overview](https://help.plytix.com/en/table-views) and from the Settings tab. This article covers managing Views from the Settings tab. ###
Creating a View 

To create a View from the Settings tab: 
1. Go to the navigation menu and click **Settings**.
2. On the left side menu, click **Views**.
3. Click the **+ New** button.

![New view](https://help.plytix.com/hs-fs/hubfs/Help%20center/Using%20Plytix/Working%20with%20Table%20Views/new%20design%202026/New%20view.jpg?width=644&height=230&name=New%20view.jpg)

4. **Name** your View.
5. Configure the View settings, such as columns, filters, sorting, Product Family, or levels displayed.
6. Click the **Save** button.

![New view (1)](https://help.plytix.com/hs-fs/hubfs/Help%20center/Using%20Plytix/Working%20with%20Table%20Views/new%20design%202026/New%20view%20(1).jpg?width=670&height=290&name=New%20view%20(1).jpg)

### Setting a View as Private or Shared

Every View is either **Private** (visible only to you, saved changes affect only your view) or **Shared** (visible to all users in the account, saved changes update the View for everyone).

This is the same Private/Shared setting described in [Working with Views](https://help.plytix.com/en/table-views#view-types). From the Settings tab, you can set or change it the same way you would from the Product Overview, from the View's own options menu.

Only the View's creator, an Account Owner, or an Account Admin can change a View between Private and Shared.

### Migrating legacy Table Views

If your account has existing Table Views, they're now in a legacy state. Table Views can no longer be created or edited, but you can migrate them into the new Views system.

When you migrate a Table View, its column setup is copied into a new View. Once the new View is saved, it's fully independent of the original Table View.

Migrating a Table View from the Settings tab:

1. Go to the navigation menu and click **Settings**.

2. On the left side menu, click **Views**.

3. Click the **+ New** button and select **From a table view (legacy)**.

![Legacy](https://help.plytix.com/hs-fs/hubfs/Help%20center/Using%20Plytix/Working%20with%20Table%20Views/new%20design%202026/Legacy.jpg?width=670&height=189&name=Legacy.jpg)

4. Click the **Save** button.

### Editing a View

You can modify a View at any time. To edit it from the Settings tab:

1. Click on the name of the View you'd like to edit.

![Edit](https://help.plytix.com/hs-fs/hubfs/Help%20center/Using%20Plytix/Working%20with%20Table%20Views/new%20design%202026/Edit.jpg?width=644&height=142&name=Edit.jpg)

2. Add attributes from **Available attributes**, remove attributes from **Selected attributes**, and change the order attributes are shown in.
3. Change the **filters**, **sorting**, **Product Family**, or **levels displayed**.
4. When you're done editing, click the **Save** button.

---

### Exporting a View

You can export a View's products and attributes directly from the Settings tab, in just a couple of clicks. The export matches exactly what's configured in that View, its columns and whichever products meet its filters.

To export a View from the Settings tab:
1. Go to the navigation menu and click **Settings**.
2. On the left side menu, click **Views**.
3. Find the View you want to export, and select the **Export as CSV** option from its options menu.

This is the same export option described in [Working with Views](https://help.plytix.com/en/table-views#exporting-view).

---

### Deleting a View 

To delete a View:
1. Click the **Delete** button that appears to the right of the search bar.
2. Confirm by typing `DELETE` in the box.
3. Click the **Delete** button.

![Delete](https://help.plytix.com/hs-fs/hubfs/Help%20center/Using%20Plytix/Working%20with%20Table%20Views/new%20design%202026/Delete.jpg?width=670&height=139&name=Delete.jpg)

⚠️  Once you delete a view, it cannot be undone.
