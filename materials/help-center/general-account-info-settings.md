### Accessing the account administration area

There are two ways to access the Account Administration area.

1. Directly by navigating to [accounts.plytix.com](https://accounts.plytix.com).

2. By clicking on your profile picture in the bottom-left corner of the platform, then on the settings icon in your profile overview. 

![Account_Settings_Overview](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Inviting%20users%20and%20managing%20your%20team/Account_Settings_Overview.png?width=670&height=357&name=Account_Settings_Overview.png)

### Info

**Account Summary**

When you enter the Account Administration area, you will be taken to the account information area, which contains a summary of all of your account's data, including:
- Number of products
- Used storage
- Team members
- Attributes
- CDN traffic
- API keys
- Channels, Brand Portals, and Product Sheets

![account-summary](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Account%20Info%20Settings/account-summary.png?width=670&height=357&name=account-summary.png)

**Credits**

In the Account Summary you can also see your AI credits balance, showing how many credits remain and how many have been consumed. It also displays the date of your next credits reset. If you need more credits, there is an **Upgrade** button available to change your plan.

**Add-ons**

Below the account summary, you will find your Add-ons section. Here you can see which add-ons are active on your account, along with the quantity in use for each one. 

At the top of the account settings area you will find your account information:

### Profile

On the left menu of the Account Information area, you'll see that below account you can click on **'Profile' **to display information specific to the user who is logged in. Here you can edit personal information including:
- Name
- Job function
- Username
- Password

![account-plan-company_details](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Account%20Info%20Settings/account-plan-company_details.png?width=670&height=357&name=account-plan-company_details.png)

### Notifications

Under the **'Account'** tab you can find the **'Notifications' **tab. Here each user can configure their notification preferences individually.

_

![account-notifications](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Account%20Info%20Settings/account-notifications.png?width=670&height=357&name=account-notifications.png)

_

**Imports (CSV upload)**

You can toggle **Email** and **In-app** notifications on or off for imports. When email notifications are enabled, you can configure:

_I want to be notified..._
- Every time an import finishes
- Only when there's a warning or error

_I want to be notified about..._
- Imports done by any user
- Only imports done by me

![notifications-imports](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Account%20Info%20Settings/notifications-imports.png?width=670&height=357&name=notifications-imports.png)

**Feeds (Scheduled imports)**

You can toggle **Email** and **In-app** notifications on or off for scheduled imports. When email notifications are enabled, you can configure:

_I want to be notified..._
- Every time a scheduled import finishes
- Only when there's a warning or error

_I want to be notified about..._
- Feeds created by any user
- Only feeds created or processed by me

![notifications-feeds](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Account%20Info%20Settings/notifications-feeds.png?width=670&height=357&name=notifications-feeds.png)

I

**Exports**

You can toggle **Email** and **In-app** notifications on or off for exports. When email notifications are enabled, you can choose which export types to be notified about:

_I want to be notified about the following exports:_
- CSV
- XLSX
- PDF
- Assets

_I want to be notified about..._
- Exports done by any user
- Only exports done by me

![notifications-exports](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Account%20Info%20Settings/notifications-exports.png?width=670&height=357&name=notifications-exports.png)

 

**Channels**

You can toggle **Email** and **In-app** notifications on or off for channels. When email notifications are enabled, you can configure:

_I want to be notified..._
- Every time a channel finishes processing
- Only when there's a warning or error

_I want to be notified about..._
- Channels created by any user
- Only channels created or processed by me

![notifications-channels](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Account%20Info%20Settings/notifications-channels.png?width=670&height=357&name=notifications-channels.png)

**Comments**

You can toggle **Email** notifications on or off for comments. When enabled, you can configure:

_I want to be notified..._
- Mentions, replies, and products I've commented on
- Only mentions and replies to my comments

![notifications-comments](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Account%20Info%20Settings/notifications-comments.png?width=670&height=357&name=notifications-comments.png)
