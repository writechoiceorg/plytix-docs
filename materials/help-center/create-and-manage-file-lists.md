# Working with Asset Lists

## How to create and use Asset Lists in Plytix

Asset lists help you organize your assets into usable segments. Use them for internal management, exports, or brand portals to set up the file sharing section. There are two types of lists: **Smart** and **Static**. This article explains what they are and shows you how to create and manage them.

 

[Creating a Smart Asset List](#smart-asset-list)

[Creating a Static Asset List](#static-asset-list)

[Removing Assets from a Static List](#removing)

[Loading an Asset List](#load)

[Renaming an Asset List](#renaming)

[Deleting an Asset List](#deleting)

 

ℹ️  This article shows how to create and use **Asset Lists**. To create **Product Lists**, you can find more information about it [here](https://help.plytix.com/en/create-and-manage-product-lists).

### Creating a Smart Asset List

Smart lists use filters to define the contents of the list. This means the system will automatically add and remove assets based on whether they meet the filter conditions you set.

 

ℹ️  Smart lists will auto-update based on the conditions you choose.

 

There are two places from where you can create a smart list:

[Asset Overview](#overview)

[Asset Lists Overview](#asset-lists-view)

#### **How to Create a Smart List from the Asset Overview**

Asset Overview is where you can see and filter through all of the assets you have in Plytix.

To create a **Smart **asset list from here:
1. Click on **'Assets' **in the side navigation menu
2. Select **'All assets' **from the dropdown
3. Add filter conditions on the left **"Filters”** menu
4. Click **'Save filters'**

![assets-lists-filtering](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-filtering.png?width=670&height=357&name=assets-lists-filtering.png)

5. Click **'Create new list'** and name it

6. Click **'Save'**

**

![assets-lists-create_new](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-create_new.png?width=670&height=357&name=assets-lists-create_new.png)

**

To **update** your Smart asset list from the asset overview:

1. Follow the above steps and select '**Update existing list**'

2. Choose a list to update from the dropwdown

3. Click '**Save**'

#### **

![assets-lists-update_existing](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-update_existing.png?width=670&height=357&name=assets-lists-update_existing.png)

**

#### **How to Create or Update a Smart List from the Asset Lists Overview**

You can also create and manage lists from the **Asset Lists Overview**.
1. Click on **'Assets'** in the navigation menu
2. Select **'Lists'** from the dropdown
3. Click on **'Create a list'** 
4. Choose **“Smart”**

![assets-lists-add](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-add.png?width=670&height=357&name=assets-lists-add.png)

5. Choose **'Smart'**

6. Name your list (_you can always change this later_)

7. Hit **'Create List'** (_You will be taken to the list detail area_)

![assets-lists-add-smart](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-add-smart.png?width=670&height=357&name=assets-lists-add-smart.png)

8. On the left side menu select your attribute and conditions to filter your assets by.

![assets-lists-add-smart-filters](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-add-smart-filters.png?width=670&height=357&name=assets-lists-add-smart-filters.png)

ℹ️ The filters added are automatically saved and your selection will be shown in the table area to the right. You can always change the filter conditions of smart lists by adding or removing attribute conditions in the **"FILTERS"** tab.

### Creating a Static Asset List

Static lists are based on assets that you hand-pick. Assets in a static list are added and removed manually.

 

ℹ️  Static lists do not update automatically.

 

You can:

[Create a Static list from the Asset List page](#static-overview)

[Add Assets to a Static list from the Asset Overview page](#add-static)

#### **How to Create a Static Asset List from the Asset Lists Overview**

1. Click on **'Assets'** in the navigation menu
2. Select **'Lists'** from the dropdown
3. Click on **'Create a list'** 
4. Choose **'Static' **
5. Name your list (_you can always change this later_)
6. Hit **'Create List' **(_This will take you to the new list's detail area_)

![assets-lists-add-static](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-add-static.png?width=670&height=357&name=assets-lists-add-static.png)

7. Click on **'Link assets' **to add Assets to this list**
**

![assets-lists-add-static-link_assets](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-add-static-link_assets.png?width=670&height=357&name=assets-lists-add-static-link_assets.png)

8. Choose the assets you want to add

9. Finish by clicking **'Link'** at the top right of the popup window

![assets-lists-add-static-link_assets-2](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-add-static-link_assets-2.png?width=670&height=357&name=assets-lists-add-static-link_assets-2.png)

#### **How to Add Assets to a Static List from the All Assets Page**

 

ℹ️ You cannot create a static asset list from the Assets Overview page; you can only add assets to an existing list. If you want o create a new static list, head over to the [Asset Lists page](#asset-lists-view).
1. Click to select assets
2. Click **'+ Add to list'**

**

![assets-lists-toolbar-add_to_list](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-toolbar-add_to_list.png?width=670&height=357&name=assets-lists-toolbar-add_to_list.png)

**

3. Select the static list you want to add the assets to

4. Click **'Link to list'**

![assets-lists-toolbar-add_to_list-2](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-toolbar-add_to_list-2.png?width=670&height=357&name=assets-lists-toolbar-add_to_list-2.png)

ℹ️  This will only allow you to link existing assets within the system. If you need to [import more assets](https://help.plytix.com/import-files), then head over to the Asset Overview.

### Removing Assets from a Static List

 

To remove assets from a static list:
1. Select the assets you want to remove
2. Click** 'Unlink'**
3. Confirm by clicking **'Unlink'** again in the popup window

####

![assets-lists-toolbar-unlink](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-toolbar-unlink.png?width=670&height=357&name=assets-lists-toolbar-unlink.png)

### Loading an Asset List

Find Assets quicker by loading a pre-created list.
1. From the **Asset Overview **page, find the "FILTERS" tab on the right-hand side. Click on **'Load filters' **

![assets-lists-load_filters](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-load_filters.png?width=670&height=357&name=assets-lists-load_filters.png)

2. Choose a list from the dropdown

3. Click **'Load'**

**

![assets-lists-toolbar-load_filters-2](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Working%20with%20Asset%20Lists/assets-lists-toolbar-load_filters-2.png?width=670&height=357&name=assets-lists-toolbar-load_filters-2.png)

** You can now view all the assets in that list.

### Renaming an Asset List

You can rename an Asset List from the list's details page: 
1. Click on the list name
2. Type in the new list name
3. Press enter

 

---

### Deleting Asset Lists

You can delete an Asset List from the Asset Lists Overview page.
1. Choose the list you want to delete by checking the box next to the list name
2. Click the **'Delete'** button that appears to the right of the search bar 
3. Confirm you want to delete by typing "**DELETE**" and click the **'Yes, delete now'** button on the bottom right of the window
