# Using Import Profiles

## How to create, load, and manage import profiles in Plytix to make importing faster and easier

When importing a CSV file of your products and attributes you must go through a matching process. Import profiles let you save the settings you choose. This way, the next time you need to import a similar CSV file, you won't need to match all attributes all over again. 

 

[Creating and Updating an Import Profile](#creating)

[Loading an Import Profile](#loading)

[Deleting Import Profiles](#deleting)

ℹ️  Import profiles are created and loaded when you are[importing data](https://help.plytix.com/import-product)

### Creating and Updating an Import Profile

To create and/or update an import profile:

1. Follow the steps to [import product data,](https://help.plytix.com/import-product) match columns to attributes, and choose your settings. 

2. Click on **'Save profile'** on the right side of the screen.

![import-save_profile](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Using%20Import%20Profiles/import-save_profile.png?width=670&height=357&name=import-save_profile.png)

💡 Save your profile_ **after** _all of your attributes have been matched in the data matching section. https://help.plytix.com/hubfs/save-profile.png

3. The "Manage profile" box will appear. Here you can: 
1.
 1. Update an existing profile by choosing the profile from the dropdown in the **'Update existing Profile'** tab. 

![import-save_profile-update_existing](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Using%20Import%20Profiles/import-save_profile-update_existing.png?width=670&height=356&name=import-save_profile-update_existing.png)

b.** Create a new profile **by clicking on the **'Create new Profile' **tab and typing a name for your new profile.  

![import-save_profile-create_new](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Using%20Import%20Profiles/import-save_profile-create_new.png?width=670&height=357&name=import-save_profile-create_new.png)

4. Click **'Save' **on the bottom-right of the box.

### Loading an Import Profile

 

⚠️ Note that an import profile will only function correctly if the columns of your CSV are in the same order as when the profile was saved. Profiles work based on column number, so adding, deleting, or changing the order of columns will not import correctly. 

To load an import profile:

1. Follow the steps to [import product data](https://help.plytix.com/import-product).

2. Click on **'Load profile'** on the right side of the screen.

![import-load_profile](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Using%20Import%20Profiles/import-load_profile.png?width=670&height=356&name=import-load_profile.png)

3. The "Manage profile" box will appear. Choose the file you want to load from the dropdown. 

![import-load_profile-manage_profile](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Using%20Import%20Profiles/import-load_profile-manage_profile.png?width=670&height=357&name=import-load_profile-manage_profile.png)

4. Click **'Load'. 

**

The settings saved to that profile will now be applied to this import. You can verify that everything is correct and start your import.  

---

### Deleting Import Profiles

To delete an import profile: 
1. Go to the navigation menu and click** 'Products'**.
2. Then click **'Import'** from the dropdown and you will be taken to the import area.
3. Click on **'Profiles' **on the left menu.
4. Check the box next to the profiles you would like to delete.
5. Click **'Delete' **and type "DELETE" to confirm.

![Using-Import-Profiles-5](https://help.plytix.com/hs-fs/hubfs/Help%20center/Getting%20Started/Using%20Import%20Profiles/Using-Import-Profiles-5.jpg?width=670&height=214&name=Using-Import-Profiles-5.jpg)
