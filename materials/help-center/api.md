# API for Plytix

## How to set up API Keys in Plytix

Plytix offers an API which enables other applications to create, edit and extract information from Plytix directly. This is essential in case you need to integrate an ERP system or any other service with Plytix. In this article, you will learn how to access the API documentation, and how to create and manage API Keys.

**ℹ️** Only Owners and Admins can create and manage API keys.

### **Creating API Keys

**

API Keys are required before you can create a successful integration with the Plytix API. 

⚠️ The API credentials allow access to manipulate the data in your account, so only share the API credentials with trusted contacts and services.

 

To create API credentials, you must have** [Admin rights.](https://help.plytix.com/en/system-roles)**

#### **How to generate an API Key**

1. Go to [accounts.plytix.com](http://accounts.plytix.com/)
2. Locate the API tab.

![api_section](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20API%20for%20Plytix/api_section.png?width=644&height=343&name=api_section.png)

3. Click **'Create API Key.'

![create_API_key](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20API%20for%20Plytix/create_API_key.png?width=644&height=343&name=create_API_key.png)

**
4. Give your Key a name and set the role of the API key, which will determine access rights.

![api_name_and_role](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20API%20for%20Plytix/api_name_and_role.png?width=644&height=343&name=api_name_and_role.png)

5. Click **'Create API Key'** to save.

![save_api_key](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20API%20for%20Plytix/save_api_key.png?width=644&height=343&name=save_api_key.png)

💡 We recommend identifying the integration or party who will be using the Key directly in the name so that you know who has access to a particular Key.

 

To copy the API Key, hover over it and click the clipboard icon. To reveal the API Password, hover over it and click the eye icon.

![show_api_password](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20API%20for%20Plytix/show_api_password.png?width=670&height=357&name=show_api_password.png)

You can also edit and delete API keys using the icons next to the assigned role.

![api_hover_options](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20API%20for%20Plytix/api_hover_options.png?width=670&height=357&name=api_hover_options.png)

### Assigning API Roles

API Roles allow you to determine how much access the API Key has to your data in the PIM.  You can assign and change an API key role in the** 'API'** tab in the Account Administration section of Plytix.

 

To assign an API Key to a new role: 
1. Go to the API Key you want to edit.
2. Click the pencil icon on the right and a pop up will appear.

![api_edit_button](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20API%20for%20Plytix/api_edit_button.png?width=600&height=319&name=api_edit_button.png)

3. Edit the Key name or choose a new role from the dropdown.

![edit_api_key](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20API%20for%20Plytix/edit_api_key.png?width=644&height=343&name=edit_api_key.png)

4. Click **'Save API Key'** to save and apply your changes.

 

⚠️ Changing an existing API Key Role can result in the malfunctioning of your integration. Check before you change!

ℹ️ API Roles are managed the same way as user roles in the Account Administration section under the** **"Roles" tab. The two types of user roles are [System Roles](https://help.plytix.com/system-roles) and custom [Team Roles.](https://help.plytix.com/team-roles-creation)
