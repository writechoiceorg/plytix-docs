Filters menu 

The Filters menu makes finding and viewing assets quick and easy. From this menu you can filter through your assets, [save filters to a Smart List,](https://help.plytix.com/create-and-manage-file-lists#smart-asset-list) or [load a pre-existing asset list](https://help.plytix.com/create-and-manage-file-lists#load). 

[![assets-overview-filters](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/Navigating%20the%20Asset%20Overview%20Page/assets-overview-filters.png?width=670&height=383&name=assets-overview-filters.png)](https://help.plytix.com/hubfs/Help%20center/asset-filter-overview.png)

#### Filter through your assets 

When you have hundreds or even thousands of assets, it can be difficult to find a specific one if you search through them one by one. Applying asset attribute filters can help you narrow down your search. 

To do this, head to "**All Assets**" 
1. Click "**Show filter**" icon
2. Select the attribute you want to filter by
3. Set the condition parameters

ℹ️  As you select attributes and define filter conditions, assets that meet them will appear in the asset table on the left.

###
Asset Overview Page

In the the Asset Overview page, you can:
- Search for an asset in the table by the asset name
- Choose if you want to view assets in a list or in a grid
- Choose from three grid sizes (small, medium, large) 
- Edit the asset columns
- Show/Hide the Filters side menu
- [Upload assets](https://help.plytix.com/import-files)

#### List View

[![assets-views-list](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/Navigating%20the%20Asset%20Overview%20Page/assets-views-list.png?width=670&height=383&name=assets-views-list.png)](https://help.plytix.com/hubfs/Help%20center/File%20Management/asset-table-overview.png)

In the list view, you can choose to see the following information: 
1. **Checkbox**
 1. This is how you can select your assets.

2. **Thumbnail**
 1. This column shows you a small thumbnail image of your asset.
 2. Hovering over the thumbnail will give you an enlarged preview.
 3. Clicking on this thumbnail will take you to that asset's details page.

3. **Asset name**

 1. This will give you the name of the asset followed by its extension.
 2. Hovering over the column name and clicking on the arrow that appears lets you order assets by this column in ascending or descending order. 
 3. Hovering over an asset's name will give you the option to open that asset's detail page in a new tab.
 4. Clicking on the asset's name will allow you to edit it right on the table
 5. You can edit the asset's name from the asset overview page or asset's detail page.

4. **Size**

 1. This column identifies the size of the asset in MB.
 2. You can reorder assets by ascending/descending order based on this column.

5. **Products linked**

 1. This column tells you how many products this asset is linked to.
 2. Clicking this number will open a window that lists all the products this asset is linked to.
 3. You can reorder assets by ascending/descending order based on this column.

6. **Privacy**
 1. This column identifies if the asset is public or private 
 2. You can reorder assets by ascending/descending order based on this column

7. **Created**

 1. This column identified the date and time this asset was created or imported into your PIM. 
 2. You can reorder assets by ascending/descending order based on this column

8. **Last modified**

 1. This column identifies the last time this asset was modified. This can include if it was _renamed, linked/unliked to a product, added/removed from a category, or replaced._
 2. You can reorder assets by ascending/descending order based on this column

9. **Category**
 1. This column identifies the customised category an asset is assigned to. Learn how to [create asset categories here](https://help.plytix.com/en/create-and-manage-file-categories).
 2. Categories cannot be reordered in ascending/descending order based on this column

10. **Extension**
 1. This column identifies the extension of your assets which can be .jpg,.mp4,.png,.pdf etc.
 2. You can reorder assets by ascending/descending order based on this column

11. **Alt text**
 1. This column shows the alt text assigned to the asset, if any. Assets without alt text will show **'None.'**
 2. Clicking into the cell lets you add or edit the alt text directly from the table, the same way you can edit an asset's name inline.
 3. You can also add or edit alt text from the [asset's detail page](https://help.plytix.com/en/overview-asset-detail-page#alt-text), or in bulk by [importing assets via a CSV](https://help.plytix.com/en/import-files-csv).https://help.plytix.com/en/overview-asset-detail-page#alt-texthttps://help.plytix.com/en/overview-asset-detail-page#alt-text

💡 The information displayed in the asset overview table is customizable (see below for further information)

💡 Hover over an asset row and click on the three dots (...) that appear to the right of the Modified Date column to open the following additional options: 

1. open

2. open in a new tab

3. download asset

4. copy link to clipboard

#### Editing the asset overview columns

The asset overview columns can be hidden, added, or re-ordered. This way you can see different attributes in your asset overview to facilitate filtering and linking with products.

To change the columns in your overview:  
1. Click '**Edit columns**' in the asset overview menu
2. Select the attributes you want to be shown on the left side
3. Re-arrange the selected attributes by dragging and dropping them
4. Click **'Save columns'

#### Grid View

[![assets-views-grid](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/Navigating%20the%20Asset%20Overview%20Page/assets-views-grid.png?width=670&height=383&name=assets-views-grid.png)](https://help.plytix.com/hubfs/Help%20center/Asset%20Management/grid-view-assets.png)

In grid view, you will see
- A thumbnail of the asset (you can choose the size of this) 
- The asset's name
- The size of the asset 

⚠️ In the grid view, you will not have the option to edit the asset information displayed

If you hover over an asset, more options will appear: 
- Click on the asset's thumbnail to expand it to full screen and show in slideshow mode. 
- Open asset in a new tab
- Download asset
- Copy download link to clipboard
