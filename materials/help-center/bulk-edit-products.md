# Editing Products in Bulk

## How to edit attributes, categories, or relationships across multiple products at once, or find and replace values in text attributes.

The easiest and quickest way to update information across multiple products is to edit them in bulk. You can bulk edit information directly from the product overview table or by importing a spreadsheet.

### Editing via Import 

To bulk edit products via import **using a spreadsheet**, follow the [import instructions](https://help.plytix.com/import-product).

Remember to:
- Include a column with the product SKU.
- Include a column for each attribute you want to change or update.
- Define how to read data during the matching process (e.g. whether to add, overwrite, or erase information). 

---

### Editing from the Product Overview Table

You can also edit products in bulk directly in Plytix. You can either edit all products or select products within a product family.

---

### Editing All Products

Select "**All Products**" in the Product Overview page. Then, switch between "Parents View" and "Variants View" to edit either only parents or only variants.

 

To bulk edit **products** from the Product Overview table: 

1. Click on the '**Products'** tab in the top navigation menu

2. Select '**All products**' from the dropdown or choose a Product Family

3. In the table, select the products you want to edit 💡 [Use filters](https://help.plytix.com/en/filtering)to narrow down your selection

4. Click the '**Edit products'** button** **that appears at the bottom of the page

![Editing Products in bulk -All Products](https://help.plytix.com/hs-fs/hubfs/Help%20center/Using%20Plytix/Editing%20Products%20in%20Bulk/New%20design%202026/Editing%20Products%20in%20bulk%20-All%20Products.jpg?width=670&height=335&name=Editing%20Products%20in%20bulk%20-All%20Products.jpg)

From here, a window will appear that allows you to choose whether to edit attributes, media, [categories](#categories), or [relationships](#relationships).

ℹ️ For the options Find and replace, Edit attributes, categories, and relationships, you can edit the variants of the selected parents in bulk. For this you simply have to select the option** 'Include all variants of selected parent products'. **

---

### Editing Attributes

To edit** attributes**:

1. Click on "**Edit attributes**"

2. Select the attribute you want to edit

3. Select or insert the new value you want to assign to this attribute

4. Click 'Save'

![Edit-attributes](https://help.plytix.com/hs-fs/hubfs/Help%20center/Using%20Plytix/Editing%20Products%20in%20Bulk/New%20design%202026/Edit-attributes.jpg?width=670&height=490&name=Edit-attributes.jpg)

💡 You can delete values from attributes in bulk. For this you simply have to select the option '**Clear content'**. 

ℹ️ When editing multiselect attributes in bulk, you have the option of replacing, removing or adding options.

---

### **Editing Categories**

To edit categories:
1. Click 'Edit' and choose the '**Edit categories'** 
2. Select the action you want to perform: '**Add'**, '**Replace'**, or '**Remove'.**
3. Select the categories you want to add, replace or remove.
4. Click '**Save'.**

![Categories](https://help.plytix.com/hs-fs/hubfs/Help%20center/Using%20Plytix/Editing%20Products%20in%20Bulk/New%20design%202026/Categories.jpg?width=670&height=582&name=Categories.jpg)

ℹ️  You may only complete one action (add, remove, replace) at a time.

---

### **Editing Relationships**

To edit a relationship:
1. Click 'Edit' and choose the '**Edit relationships'** option 
2. Select the action you want to complete: "**Add**" or "**Remove**" a relationship.
3. Select the relationship you would like to edit.
4. Select the product from which you want to add or remove the association.
5. Click '**Save'**.

![Edit relationships](https://help.plytix.com/hs-fs/hubfs/Help%20center/Using%20Plytix/Editing%20Products%20in%20Bulk/New%20design%202026/Edit%20relationships.jpg?width=670&height=574&name=Edit%20relationships.jpg)

💡 When adding a relationship you can also set a quantity. 

ℹ️ You can add up to 300 products as a relationship at a time. 

---

### Editing through Find and Replace

To edit through "**Find and replace**":

1. Click on "**Find and replace**"

2. Select the attribute you want to edit

3. Click **"****Match case"** if you want to only replace values with the same upper and lowercase characters as your target.

4. Under **"Find,**" type the text you want to find

5. Under **"Replace with" **type the text you want to replace it with

6. Click** "Save"**

![Find and replace](https://help.plytix.com/hs-fs/hubfs/Help%20center/Using%20Plytix/Editing%20Products%20in%20Bulk/New%20design%202026/Find%20and%20replace.jpg?width=670&height=520&name=Find%20and%20replace.jpg)

ℹ️ Only text attributes (**short text, paragraph, and label**) can be edited with the "find and replace" action.
