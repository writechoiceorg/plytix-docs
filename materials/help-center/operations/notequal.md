# NE Operation

## How to use the NE operation in formulas

### Definition

The NE operation tests if a value is not equal to another.

### Example

NE(1,8)

Result:
true

### Syntax Guide

NE(value1, value2)

value1 - The value

value2 - The value to test against value1 for inequality
