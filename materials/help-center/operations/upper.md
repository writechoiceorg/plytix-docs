# UPPER Operation

## How to use the UPPER operation in formulas

### Definition

The UPPER operation converts a whole text string to UPPERCASE letters.

### Example

UPPER("Hello World")

Result:
HELLO WORLD

### Syntax Guide

UPPER(text)

text - The string to convert to uppercase
