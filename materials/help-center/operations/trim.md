# TRIM Operation

## How to use the TRIM operation in formulas

### Definition

The TRIM operation removes all extra spaces from a text, leaving only a single space between words.

### Example

TRIM(" Hello           World        ")

Result:
Hello World

### Syntax Guide

TRIM(text)

text - The string to be trimmed
