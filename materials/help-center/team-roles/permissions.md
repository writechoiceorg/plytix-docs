# Setting Permissions for Team Roles

## How to set and manage permissions for team roles

Team roles is a paid feature that allows admins in an account to create custom permissions for users. Team roles with custom permissions make for seamless team collaboration in Plytix. In this article you will learn about the different permission types and what they do.

### General Permissions

When you [create a team role](https://help.plytix.com/team-roles-creation), you must set the role's permissions. Permissions are grouped into Account Management and Product Information Management (PIM).

![1 - Activate PIM privileges](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Team%20roles/1%20-%20Activate%20PIM%20privileges.png?width=670&height=357&name=1%20-%20Activate%20PIM%20privileges.png)

To the right of each section, you will see a toggle. You can toggle these switches to turn the permission on/off for the role you are managing. 
- If the switch is toggled ON for Account Management, users with this role will be able to edit and view all of the Account Administration area. 
- If the switch is toggled ON for Product Information Management, a new section will open up with more granular settings for the PIM permissions. 

---

### PIM Permissions

If the switch is toggled ON for PIM permissions, you will see a new set of permissions. 

Here you are able to set the permission types to** 'Edit,'** **'View,'** or in some cases **'None.'** **** **** ****

| Edit | This permission allows a user to add and delete information. |
| --- | --- |
| View | This permission allows a user to read information, but not to make changes. In the case of products, this permission allows users to export and filter information from the Product Overview. |
| None | This permission means a user cannot view this information or area. |

 

**PIM permissions include: **
- **Products - **This covers all aspects of managing all products, and product lists. This only has two options: Edit and View.
NOTE: Users with "View" access will not be able to edit products or attributes.

Under "**product-level access**," you can edit permission rights for: 
 - **Attributes: **This limits whether a user can change attribute values at a product-level or only view attributes. You can also manage permissions for specific attributes; learn how to do it [here](//help.plytix.com/en/attribute-level-permissions).
 - **Families: **Here you can choose whether a role can edit or only view the families and variants tab at a product-level.

-
 - **Categories: **When you select "Edit" for this option, the role will be able to assign categories at a product-level or modify what categories products belong to.
 - **Relationships: **When this option is set as "Edit," the role will be able to add or remove relationships at a product-level.

- **Import: **Here you can choose what kind of permission the role will have when it comes to accessing imports, feeds, profiles, and logs. This can be set as "Edit," "View" or "None." If "None" is selected, the role will not have any access to import information.

![2 - Products](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Team%20roles/2%20-%20Products.png?width=670&height=357&name=2%20-%20Products.png)

- **Settings Management: **In this section you can edit permission rights for the "Settings" tab (you can find it located under the "Automations" in the side menu of the page). In this tab, roles can either edit the information or not have access to it at all ("Edit"/"None").

![3 - Settings](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Team%20roles/3%20-%20Settings.png?width=670&height=357&name=3%20-%20Settings.png)

- **Assets - **This covers all aspects of managing assets and asset lists. This only has two options: "Edit" and "View". Asset Category settings also have only two options: "Edit" and "None".

![4 - Assets](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Team%20roles/4%20-%20Assets.png?width=644&height=343&name=4%20-%20Assets.png)

- **Connections - **This permission affects access to Dropbox and FTP connections. This only has two options: "Edit" and "None".**

![5 - Connections](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Team%20roles/5%20-%20Connections.png?width=644&height=343&name=5%20-%20Connections.png)

**
- **Add-ons**
 - ****Brand Portals - ****Access designer and brand portal settings. This has all options: "Edit", "View", and "None".

-
 - **Channels - **Access channel setup and management. This has all options: "Edit", "View", and "None".
 - Product Data Sheets - Access product data sheets settings. This has all options: "Edit", "View", and "None".

![6 - Add-ons](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Team%20roles/6%20-%20Add-ons.png?width=584&height=311&name=6%20-%20Add-ons.png)

ℹ️ Permissions for Brand Portals, Channels, and Product Data Sheets, will only appear for outputs activated in your account. 
-

**Automations -** This permission affects  the ability to automate actions based on specific conditions to streamline processes. This has all options: "Edit", "View", and "None".**
**

### Attribute-Level Permissions

Attribute-level permissions allow you to set whether individual attributes can be edited or only viewed by users in your account. Unlike team roles, attribute-level permissions can be found by clicking on **'Settings' **in the main navigation bar. Learn how to set permissions at an attribute-level [here](//help.plytix.com/en/attribute-level-permissions).
