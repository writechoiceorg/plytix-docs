# Editing Product Attributes

## How to edit product information at an attribute level in Plytix

Product Attributes are the properties or fields that allows you to assign values to your products (e.g. _Color_, _Brand_, _Description_, _etc._). This helps you build out your specifications and other rich content. In this article, we will show you the different ways you can edit and update your product information at an attribute level.

### Editing Attributes from the Product Overview

There are a few ways you can edit product attributes from the [Product Overview](https://pim.plytix.com/products). You can either perform a bulk editing action or edit attributes in-table. 

#### Bulk Editing

If you need to update multiple products at the same time, this is the best way to do this. So when you are on the Product Overview page:

1. Choose between **Parents View** or **Variants View**.

2. Select the products you want to edit. 3. Click the **Edit products** button.

![1-Edit selected products](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Edit%20product%20attributes/1-Edit%20selected%20products.png?width=670&height=357&name=1-Edit%20selected%20products.png)

4. Choose up to 3 different attributes to edit and input the new values

5. Click the **Save** button.

ℹ️ When editing Multiselect Attributes, you will be able to define whether you want to replace, remove, or add any options.

ℹ️ Learn more about [bulk editing options](https://help.plytix.com/en/bulk-edit-products) here.

#### In-table Editing

The Product Overview also has in-table editing enabled so that you can work faster. This is great for on-the-fly changes. Almost all attribute types can be updated in the table, with the exception of media attributes.

To do in-table editing: 
1. Go to the product you want to edit.
2. Find the attribute you want to change and click on the cell in the table.

![2-Edit field](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Edit%20product%20attributes/2-Edit%20field.png?width=644&height=343&name=2-Edit%20field.png)

3. Make the changes to the attribute.
4. Press the **Enter** key on your keyboard to save your changes.

💡 If you're editing a longer piece of content from within the Table View, you can stretch the editing box by expanding the column width, which makes working from within the Table View easier.

You can edit an attribute's settings by hovering over its name and clicking the arrow highlighted below. This will open a modal to configure your attribute settings without having to leave the page.

![3-Add a role](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Edit%20product%20attributes/3-Add%20a%20role.png?width=670&height=357&name=3-Add%20a%20role.png)

For **multiselect** and **dropdown** attributes, you can also search existing options and create new ones by clicking on the attribute value directly in the cell.

For **multiselect** attributes, click the **+** icon next to the attribute value. For **dropdown** attributes, type in the attribute you'd like to search for or create, and press the **Enter** key on your keyboard.

![4-Add a role](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Edit%20product%20attributes/4-Add%20a%20role.png?width=670&height=357&name=4-Add%20a%20role.png)

### Editing Attributes from the Product Detail Page

Of course, you can also enter into a single product to edit the attributes of that product. 

To do this: 
1. Find the product you want to edit in the Product Overview and click on the SKU to enter the Product Detail view.
2. From this view, you can browse through attributes by selecting your custom view of **Attribute Groups** at the top.
3. To edit an attribute, click the **pencil** icon that appears when hovering over an attribute to enable editing.

![5-Two column view](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Edit%20product%20attributes/5-Two%20column%20view.png?width=670&height=357&name=5-Two%20column%20view.png)

![6-Completeness tracking](https://help.plytix.com/hs-fs/hubfs/Help%20center/Help%20Center%20Images/HC%20-%20Edit%20product%20attributes/6-Completeness%20tracking.png?width=670&height=357&name=6-Completeness%20tracking.png)

⚠️ If you edit an attribute that a variant inherits from its parent, your new value overwrites the inherited one for that variant only. If you've overwritten an inherited attribute this way, you can resync it to match the parent-level value again.

4. Make the changes you want, then either press the **Enter** key on your keyboard or click the **checkmark** icon to temporarily save while you make other changes.

5. Click the **Save Changes** button at the top left to apply and save your changes permanently.

💡 Find attributes quickly by using the attribute search bar.

💡 Choose a two-column layout to see different attribute groups side-by-side to help improve translation and enrichment inputs.

### Editing a Variant's Attributes

If you're on a parent product's Detail page and open its **Variants** tab, keep in mind that this table is for viewing and managing which variants belong to that parent, you can't edit a variant's attributes directly from within it.

To edit a variant's attributes, use one of the methods already covered in this article instead:
- From [Product Overview](#overview), switch to **Variants View** and edit the variant there, using bulk editing or in-table editing.
- Open the variant's own Product Detail page (click into that specific variant's SKU) and [edit its attributes there](#detail).

Editing attributes for a variant works exactly the same way as editing them for any other product, the only difference is that a variant's own Detail page is reached by clicking into it from Product Overview or from a search, rather than from its parent's Variants tab.
