          Create a new product family.


          Upon successful creation, a 201 CREATED status code is returned and
          product family can be found in response body.


          | Parameter | Type | Mandatory | Description |

          | --- | --- | --- | --- |

          | name | string | **yes** | human friendly name |

          | attributes | list | **no** | List of attribute IDs or objects that
          include a label and, optionally, an id.  <br>  <br>**\*attributes with
          inheritance OFF** |

          | parent_attributes | list | **no** | List of attribute IDs or objects
          that include a label and, optionally, an id.  <br>  <br>**\*attributes
          with level 1 inheritance ON** |

          | variant_attributes | list | **no** | List of attribute IDs or
          objects that include a label and, optionally, an
          id.  <br>  <br>**\*attributes with level 2 inheritance ON** |


          > _"attributes"_, _"parent_attributes"_, and _"variant_attributes"_
          can each be provided as either a list of IDs or a list of objects
          containing a label and, optionally, an id. You cannot mix IDs and
          objects within the same request. Attributes can also be sent as
          objects to define the inheritance level for system attributes. 
            
          > The "parent_attributes" and "variant_attributes" options are
          available only when automatic inheritance is active on the account.
          Contact your account manager for more information.
