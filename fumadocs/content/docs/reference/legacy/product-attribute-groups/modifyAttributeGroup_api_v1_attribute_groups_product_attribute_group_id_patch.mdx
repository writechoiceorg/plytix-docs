          Allowed properties:


          | Field | Type | Description |

          | --- | --- | --- | 

          | name | string  | product attribute group friendly-name |

          | attribute_labels | array of strings | array of user attribute

          |

          | order | number | position of this group  **using zero-based
          numbering**, so the first group will be ordered starting with 0  |


          A 200 OK is returned upon successful request


          * order: if group order is greater than the number of existing groups,
          group will be moved to the last position

          * attribute_labels: If present, group will be modified. Please note
          that a request like 'attribute_labels': null will remove ALL
          attributes from this group
