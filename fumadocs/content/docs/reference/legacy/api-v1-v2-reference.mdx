This is the reference for Plytix's V1 API, plus the small set of V2 (beta) endpoints that mirror some V1 product operations with a slightly different shape. New integrations should use [API Reference (V3)](/docs/reference/v3); see [Migrating to V3](/docs/guides/migrating-to-v3) for what's different and how to migrate.

Every request here uses the same bearer-token authentication as V3: get a token from [`POST /auth/api/get-token`](/docs/reference/legacy/authentication/retrievesAnAuthenticationToken_auth_api_get_token_post) and send it as `Authorization: Bearer <token>`.

## About this reference

This reference was generated from Plytix's internal V1 Postman collection, not from a machine-readable spec, so request/response schemas and examples are inferred from that collection's saved examples rather than a live source of truth. Cross-check against the live API with a real request before relying on an exact field name or type.
