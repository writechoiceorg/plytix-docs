          **⚠️ Keep in mind that converting a Single product to a Parent might

          | **field** | **Mandatory** | **Description** |

          | --- | --- | --- |

          | sku | yes | sku for the new product |

          | label | no | label for the new product. Any other System attribute
          can be set at the same level |

          | attributes | no | custom attribute values for the new products. If
          you add a parent-level attribute here it will be set as Overwritten |
