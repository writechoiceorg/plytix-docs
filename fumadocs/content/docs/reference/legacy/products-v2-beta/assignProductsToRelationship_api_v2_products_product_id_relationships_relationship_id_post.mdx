          **Note:** If the payload includes a product that doesn't exist or has

          # Request format


          To assing a product to any relationship, the id of the product to be
          related along with its quantity must be provided.


          | _field_ | _type_ | _description_ |

          | --- | --- | --- |

          | product_relationships | Array of objects | list with product and
          quantities |


          A _product_relationship_ object is defined by:


          | _field_ | _type_ | _description_ |

          | --- | --- | --- |

          | product_id | string | product identifier |

          | quantity | number | relationship quantity |
