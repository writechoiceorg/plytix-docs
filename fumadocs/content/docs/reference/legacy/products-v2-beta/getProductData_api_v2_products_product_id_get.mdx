          Gets product attributes


          Every product has two sets of attributes, first set is always returned
          when you GET a  

          product and its formed by attributes shown in the following table.


          | Parameter | Type | Readonly | Mandatory |

          | --- | --- | --- | --- |

          | _**sku**_ | string |  | **yes** |

          | label | string |  |  |

          | gtin | string |  |  |

          | id | string | **yes** |  |

          | created | date | **yes** |  |

          | modified | date | **yes** |  |

          | num_variations  <br>  <br>\* _Number of variants connected to the
          product_ | integer | **yes** |  |

          | status | string |  |  |

          | asset_ids | string array |  |  |

          | category_ids | string array |  |  |

          | thumbnail | string array |  |  |

          | attributes | object |  |  |

          | product_family_id | string | **yes** |  |

          | overwritten_attributes | string array | **yes** |  |

          | product_type | string | **yes** |  |


          The second set of attributes is formed by custom product attributes
          and only will be returned if they are set. Empty attributes will be
          stripped from the output.


          This API version supports the following set of custom attributes:


          | Parameter | Type |

          | --- | --- |

          | Short text | string |

          | Paragraph | string |

          | Rich text | string |

          | Integer number | integer |

          | Decimal number | decimal |

          | Dropdown | string |

          | Multiselect | string array |

          | URL | string |

          | Media | string array |

          | Media Gallery | string array |

          | Boolean | bool |

          | Date | String date  <br>ISO 8601 Format |


          Notice that this endpoint **will not return the media or categories
          structure.** To get that endpoints you have to make another request
          with the specific endpoint


          200 code is returned upon success
