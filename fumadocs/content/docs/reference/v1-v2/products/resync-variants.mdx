          Restore the attributes at parent level of the variant with the value
          of the parent


          It's necessary to send two list, one with the labels of the attributes
          and another with the ids of the variant products.


          | **field** | **Mandatory** | **Description** |

          | --- | --- | --- |

          | attribute_labels | yes | List of attribute labels to reset. These
          attributes must be at a parent level |

          | variant_ids | yes | List of variant ids that are going to restore
          the value for the parent attributes. These ids must be variants of the
          parent product |


          A 200 OK is returned upon success.
