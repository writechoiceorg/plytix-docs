Plytix enforces rate limits on the API so that no single account can degrade the platform for everyone else. This page covers how those limits work on V1/V2, what happens when you exceed them, and where to check the limits for your plan.

<Callout type="warn" title="Checking your plan's limits">
  Rate limits vary by account plan. To confirm the limits that apply to your account, ask your account manager.
</Callout>

## How rate limits work

Every request counts as one hit. For each hit, the API checks two conditions: you haven't reached your plan's limit for requests per 10 seconds, and you haven't reached its limit for requests per hour. A request counts against both windows at the same time, so whichever window you exhaust first blocks you.

Your account plan sets the limits, and they apply to all resources in the API. The standard plans have these limits:

| Account plan | Per 10 seconds | Per hour |
|---|---|---|
| Free | 20 requests | 2,000 requests |
| PRO and Standard+ | 50 requests | 5,000 requests |

## Exceeding your limit

If you reach either limit, the API returns a `429 TOO MANY REQUESTS` status code. Every request you make keeps returning `429` until the time interval for the limit you hit expires. Pause when you see a `429` instead of retrying right away. See [Errors and status codes](/reference/v1-v2/errors-status-codes) for the full list of status codes the API returns.
