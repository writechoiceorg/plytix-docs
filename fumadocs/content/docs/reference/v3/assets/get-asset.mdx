          returns `404`.


          `data` holds the asset object itself, not a list. Asset records don't
          currently include a download URL.


          To see which asset categories the asset belongs to, add
          `_fields=categories`, or use [Get an asset
          field](/reference/v3/assets/get-asset-field) with `categories`.
