    contents:
      - content: >-
          Removes one link from an asset. `categories/<category_id>` takes the
          asset out of that asset category.


          A successful call returns `204` with an empty body. Only that one link
          is removed: the asset, the category, and the asset's other links stay
          as they are.


          A collection without an ID, such as `categories` on its own, returns
          `405`. An ID that isn't linked to the asset returns `404`.


          To delete the asset itself, use [Delete an
          asset](/docs/reference/v3/assets/delete-asset). See [Update and delete
          records](/docs/reference/v3/updates-and-deletes).
