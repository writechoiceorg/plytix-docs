          Returns part of an asset without the rest of the record. Set `path` to
          `categories` to get the asset categories the asset belongs to.


          `data` is a list, empty when the asset belongs to no category. Changes
          to these links show up right away.


          A field the asset doesn't have returns `400`, and the message lists
          the asset's fields. Assets have no `attributes`, `relationships`, or
          `products` field, so those return `400` too.
