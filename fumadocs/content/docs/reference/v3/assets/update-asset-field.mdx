  structuredData:

    contents:
      - content: >-
          Changes one field of an asset and leaves the rest as it is. Set `path`
          to the field, for example `alt_text`, and send the new value on its
          own as the request body: `"Adventure mug in blue, front view"`, not
          `{"alt_text": "Adventure mug in blue, front view"}`. A successful
          update returns `204` with an empty body.


          This differs from [Update an
          asset](/reference/v3/assets/update-asset), which takes an object with
          the fields to change. See [Update and delete
          records](/reference/v3/updates-and-deletes#change-a-single-field).
