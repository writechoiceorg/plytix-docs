      - content: >-
          Returns the assets in your Plytix DAM that match your filters, one
          page at a time.


          Use it to find an asset's `id` before you read, update, or delete it,
          or to list the files in your account page by page.


          Filters are query parameters written as `field=value` or
          `field[operator]=value`. An asset must match all of them, unless you
          group filters with `_or`.


          Each asset describes its file: `filename`, `extension`,
          `content_type`, `file_type`, and `file_size`. `path` is the file's
          storage path inside Plytix, not a download URL, and the record has no
          URL field.


          `n_products` and `n_catalogs` count the products and catalogs that use
          the asset. Check them before you delete an asset.


          Results come back 25 per page by default, up to 1000 with
          `_page_size`. To get the next page, follow `pagination.next_page`. On
          the last page that key is left out, not set to `null`. The link starts
          with `http://`, so change it to `https://` before you follow it.
          Otherwise the redirect can drop your `Authorization` header. The
          response doesn't include a total count.


          Related pages:


          - [Filtering and search](/reference/v3/filtering-and-search)

          - [Pagination](/reference/v3/pagination)

          - [The Plytix data model](/docs/guides/data-model#assets)
