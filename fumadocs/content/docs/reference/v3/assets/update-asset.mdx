    contents:
      - content: >-
          Changes an asset's `filename` or `alt_text` and leaves every other
          field as it is. A successful update returns `204` with an empty body.
          To see the result, read the asset back.


          Only `filename` and `alt_text` can be changed. You can't replace the
          file itself: to use a different file, create a new asset.


          The body accepts only these two fields. `category_ids` returns `422`
          with "Extra inputs are not permitted". To take an asset out of a
          category, use [Unlink a category from an
          asset](/reference/v3/assets/delete-asset-field).


          To change one field, you can also use [Update an asset
          field](/reference/v3/assets/update-asset-field). See [Update and
          delete records](/reference/v3/updates-and-deletes).
