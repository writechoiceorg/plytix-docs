          Returns the attribute groups in your account, one page at a time. Each
          group has a `name`, an `order` (its display position), and
          `attribute_labels`, the labels of the attributes it contains.


          Groups organize attributes for display. They don't change which
          attributes a product can hold. Product families control which
          attributes apply to their products. See [The Plytix data
          model](/docs/guides/data-model#product-attributes).
