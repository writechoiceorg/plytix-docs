  structuredData:
    headings: []
    contents:
      - content: >-
          Links an existing attribute to the product family, so products in the
          family can hold a value for that attribute. Send the attribute's ID in
          `attribute_id`, and optionally a `level`. Without `level`, the
          attribute is linked at `no_level`.


          A successful link returns `201` with the new link record. A body
          without `attribute_id` returns `422`.


          To link an attribute without a request body, use [Link an attribute to
          a product family by
          URL](/reference/v3/family-attributes/add-attribute-to-family-by-id).
          See [The Plytix data
          model](/docs/guides/data-model#product-families-and-variants) for how
          levels work, and [Update and delete
          records](/reference/v3/updates-and-deletes) for how writes behave
          across the V3 API.
