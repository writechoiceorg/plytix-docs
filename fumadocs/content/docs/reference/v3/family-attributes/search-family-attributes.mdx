      - content: >-
          Returns the links between product families and attributes in your
          account, one page at a time. Each record names a `product_family_id`,
          an `attribute_id`, and the link's `level`.


          To get one family's attributes, filter by `product_family_id`. Without
          a filter, the search covers every product family in your account.


          `level` sets how the attribute's values pass down a family's
          hierarchy:


          - `parent_level`: a parent's value passes down to its variants and
          sub-variants.

          - `variant_level`: a variant's value passes down to its sub-variants.

          - `no_level`: values don't pass down.


          `level` is `null` when the attribute has no level. See [The Plytix
          data model](/docs/guides/data-model#product-families-and-variants).


          To get the product family or the attribute as a full record, with the
          attribute's name and type, add `_fields=product_family` or
          `_fields=attribute`. These relations come back only when you name them
          in `_fields`.


          Related pages:


          - [Filtering and search](/reference/v3/filtering-and-search)

          - [Pagination](/reference/v3/pagination)
