  toc: []
  structuredData:
    headings: []
    contents:
      - content: >-
          Change an existing family-attribute link’s `level`, moving the
          attribute between the family’s inheritance tiers: `no_level`,
          `parent_level`, or `variant_level`. Raising an attribute to
          `parent_level` is what makes a parent’s values flow down to its
          variants.


          > **Warning:** This requires the automatic-inheritance feature on your
          account. Without it, every level change returns `403 PermissionError`
          with "Automatic inheritance is not available for this account",
          whatever the target level. That’s an account-plan gate rather than a
          problem with the request; contact your account manager to have the
          feature enabled.


          `level` is the only part of a link that can be updated. To change
          which attributes a family has, link and unlink them with [Add an
          attribute to a
          family](/reference/v3/family-attributes/add-attribute-to-family) and
          [Remove an attribute from a
          family](/reference/v3/family-attributes/remove-attribute-from-family).
