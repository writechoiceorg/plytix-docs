          Fetch a single family-attribute link by its two IDs. Returns the one
          record: `{product_family_id, attribute_id, level, account_id}`.


          Use this to check whether a specific attribute applies to a family. If
          it isn’t linked, the response is `404` with a `NotFoundError`
          describing the missing association.


          To list every attribute on the family instead, use [List a family's
          attributes](/reference/v3/family-attributes/list-family-attributes).
