    contents:
      - content: >-
          Link an attribute to a product family, taking `attribute_id` from the
          URL instead of the request body. It needs no body, and is otherwise
          the same action as [Add an attribute to a
          family](/reference/v3/family-attributes/add-attribute-to-family).


          If the attribute is already linked to that family, this returns `409
          AlreadyExists` rather than linking it twice.


          Use the collection form when you want to set the attribute’s `level`
          in the same call; this form always links at the family’s default.
