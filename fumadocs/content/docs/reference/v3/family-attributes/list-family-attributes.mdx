  structuredData:
    headings: []
    contents:
      - content: >-
          Returns the attributes linked to one product family, with each link's
          `level`. Each record names the `product_family_id`, the
          `attribute_id`, and the `level`, which is `parent_level`,
          `variant_level`, `no_level`, or `null` when the attribute has no
          level.


          To get the attribute as a full record, with its name and type, add
          `_fields=attribute`. To get the product family, add
          `_fields=product_family`. These relations come back only when you name
          them in `_fields`.


          To filter or page through links, including across families, use
          [Search family
          attributes](/reference/v3/family-attributes/search-family-attributes).
