      - content: >-
          Link an existing attribute to a product family, so that products in
          the family can carry that attribute.


          Send `{"attribute_id": "<id>"}`. The attribute has to exist already.
          Create it first with [Create a product
          attribute](/reference/v3/product-attributes/create-product-attribute).
          A successful call returns `201`.


          `level` is optional and sets the attribute’s inheritance tier in this
          family (`no_level`, `parent_level`, or `variant_level`). Omit it and
          the attribute is linked at `no_level`.


          > **Warning:** `parent_level` and `variant_level` require the
          automatic-inheritance feature on your account. Without it, setting
          either returns `403 PermissionError` with "Automatic inheritance is
          not available for this account", and only `no_level` links can be
          created. See [Update a family
          attribute](/reference/v3/family-attributes/update-family-attribute)
          for the same gate on changing a level later.


          To link by URL instead of in the body, use [Add an attribute to a
          family by
          ID](/reference/v3/family-attributes/add-attribute-to-family-by-id).
          Use this collection form when you want to set `level` in the same
          call.
