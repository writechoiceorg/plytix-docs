          Returns the asset categories in your account that match your filters,
          one page at a time.


          Asset categories organize assets in their own tree, separate from
          product categories. Each category has a `name`, a `parent_id` (in
          search results, a top-level category has no `parent_id` key), a `path`
          with the names from the top of the tree down to it, a `slug`, and an
          `n_children` count.


          Filters are query parameters written as `field=value` or
          `field[operator]=value`. A category must match all of them, unless you
          group filters with `_or`.


          Results come back 25 per page by default, up to 1000 with
          `_page_size`. To get the next page, follow `pagination.next_page`. On
          the last page that key is left out, not set to `null`. The link starts
          with `http://`, so change it to `https://` before you follow it.
          Otherwise the redirect can drop your `Authorization` header. The
          response doesn't include a total count.
