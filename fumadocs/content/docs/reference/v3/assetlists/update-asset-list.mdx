      - content: >-
          Renames an asset list, replaces a `Smart` list's `query`, or both. A
          successful update returns `204` with an empty body. To see the result,
          read the list back.


          Send `query` only for a `Smart` list. A `query` you send replaces the
          list's whole query. It isn't merged with the old one, so include every
          group and condition you want to keep. Renaming a list without sending
          `query` leaves the query as it is.


          The body accepts only `name` and `query`. You can't change a list's
          `type`. See [Update and delete
          records](/docs/reference/v3/updates-and-deletes).
