          Returns the product-to-product links in your account, one page at a
          time. Each record links one `product_id` to one `related_product_id`,
          with the link's `quantity`.


          To get every product related to one product, filter by `product_id`.
          This is how to read a product's related products: a product's own
          `product_relationships` field lists only the relationship types it
          uses.
