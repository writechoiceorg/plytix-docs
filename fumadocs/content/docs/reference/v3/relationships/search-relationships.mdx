      - content: >-
          Returns the relationship types in your account, such as "Gift basket"
          or "Recommended products", one page at a time. A relationship type
          names a kind of connection between products. It doesn't hold the
          product links themselves.


          Each record holds the type's `id`, its `name`, its `label`, and its
          `status`. A product's `product_relationships` field names each type it
          uses by `relationship_id`, which matches `id` here.


          Filters use the same syntax as every V3 search, for example
          `status=ACTIVE`. To sort by name, send `_sort_by=name`.


          To see which products are linked under a type, use [Search related
          products](/reference/v3/related-products/search-related-products), for
          example with `product_id=<id>` to get the products on the other end of
          one product's links.
