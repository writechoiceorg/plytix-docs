          change here, and other fields return `422`. A successful update
          returns `204` with an empty body.


          The `label` stays as it was when the type was created, so a type
          renamed from "Spare Parts" to "Replacement Parts" keeps the label
          `spare_parts`. See [Update and delete
          records](/reference/v3/updates-and-deletes).
