      - content: |-
          Creates a relationship type, such as "Spare Parts", and returns it, including its new `id`. `name` is the only field in the body.

          Plytix sets the other fields for you:

          - `label` is derived from the name in snake_case, so "Spare Parts" gets `spare_parts`. It doesn't change if you rename the type later.
          - `status` starts as `ACTIVE`.

          Names are unique in your account. If a relationship type with that name already exists, the request returns `409` and creates nothing.

          Creating a type doesn't link any products. To see which products use a type, use [Search product relationships](/reference/v3/product-relationships/search-product-relationships). See [The Plytix data model](/docs/guides/data-model#relationships) and [Update and delete records](/reference/v3/updates-and-deletes).
