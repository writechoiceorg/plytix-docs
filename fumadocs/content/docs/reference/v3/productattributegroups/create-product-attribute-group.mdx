      - content: >-
          Creates an empty attribute group and returns it, including its new
          `id` and its `order`. Only `name` is required, and it's the only field
          the body accepts.


          A successful create returns `201` with the new group in `data`. Its
          `attribute_labels` starts empty. If a group with the same name already
          exists, the request returns `409` and creates nothing.


          You can't add attributes in the same request: `attribute_labels`
          returns `422` with "Extra inputs are not permitted".


          See [Update and delete
          records](/docs/reference/v3/updates-and-deletes).
