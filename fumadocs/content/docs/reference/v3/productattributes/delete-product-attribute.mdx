          with an empty body, and a later request for the attribute returns
          `404`.


          Products key their values by the attribute's `label`, so check which
          products hold a value before you delete an attribute: filter products
          with `attributes.<label>[exists]=true`. See [Filtering and query
          syntax](/docs/reference/v3/filtering-query-syntax) and [Update and
          delete records](/docs/reference/v3/updates-and-deletes).
