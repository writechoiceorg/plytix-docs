          Fetch a single field from a product without pulling back the entire
          product record.


          Use the product's Plytix `id` as `identifier`, not its SKU.


          > **Warning:** The `categories`, `assets`, and `static_lists` subpaths
          return an empty array even when the product genuinely has those links.
          Don't use them to check membership, and don't treat an empty result as
          proof that a write didn't apply. Read those fields through the search
          endpoint instead, with `_fields`, for example `GET
          /products?sku=BAG-10157&_fields=categories&_fields=assets`. The
          `relationships` subpath is unaffected and returns real data.
