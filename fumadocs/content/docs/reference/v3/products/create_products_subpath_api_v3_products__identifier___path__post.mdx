      - content: |-
          Add a field to a product. `API V3.md` documents this as working on attributes only, with empty values such as `""` and `[]` stored as values rather than treated as a deletion.

          To set an attribute value today, use [Update-Products](/docs/reference/v3/products/update_products_api_v3_products__identifier__patch) with `{"attributes": {"<name>": "<value>"}}`. That applies whether or not the product already holds a value for that attribute, which covers what this endpoint is meant to do.

          Use the product's Plytix `id` as `identifier`, not its SKU.

          > **FLAG:** This method isn't confirmed to work on products. On every other Plytix resource tested, product families and PIM product lists, the same subpath POST returns `405 Method Not Allowed`, including for field names that a PATCH on the identical URL updates. Confirm against a live product before publishing, and point readers at the root PATCH until then.
