          Delete a single field from a product. In practice this does not provide scoped removal of a link.

          A recognized collection name, such as `DELETE /products/{id}/categories`, returns `405 Method Not Allowed` because there's no single well-defined write target. Any other path, including the three-segment `/categories/{category_id}` unlink form, returns `404 Not Found`. The product is left intact in both cases.

          To remove one category, asset, or relationship, PATCH the product with the reduced array instead. See [Safely remove categories, assets, or relationships](/docs/guides/safely-removing-categories-assets-or-relationships).
