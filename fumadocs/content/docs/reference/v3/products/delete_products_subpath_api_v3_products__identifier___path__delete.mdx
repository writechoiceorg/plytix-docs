          > **Warning:** this endpoint does not do what its path suggests. Sending `DELETE` to a product subpath, for example `DELETE /products/{id}/categories`, deletes the entire product, not just that field or sub-resource. This has been confirmed in testing, including against subpath names that don't correspond to anything real, so the behavior isn't scoped to any specific field: it deletes the whole product regardless of what path you send.

          Never use this endpoint expecting a partial removal. To remove a category or clear a thumbnail without deleting the product, see [Safely remove categories, assets, or relationships](/docs/guides/safely-removing-categories-assets-or-relationships).
