      - content: >-
          Returns the value of one product field without the rest of the record.
          Set `path` to the field:


          - `attributes` returns the product's custom attribute values as a map,
          and `attributes/<label>` returns one attribute's value.

          - `categories` and `assets` return the records linked to the product.


          `data` holds the value itself, so its shape depends on the field. A
          field the product doesn't have returns `400`, naming the field.
