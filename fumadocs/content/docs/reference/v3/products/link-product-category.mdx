title: Link a category to a product
full: true

    - ./openapi.json
  method: POST
  path: "/api/v3/products/{identifier}/categories"
  webhook: false
  toc: []
  structuredData:
    headings: []
    contents:
      - content: >-
          Files a product under one existing product category. Send the
          category's ID as `{"id": "<category_id>"}`. A successful link returns
          `201` with the linked category's ID.


          Send one category per request: the body doesn't take a list of IDs.
          The product's other categories stay linked.


          If the category is already linked to the product, the request returns
          `409` and nothing changes. A category ID that doesn't exist returns
          `404`.


          Products don't accept `category_ids` on create or update (`422`), so
          this is how to add a category to a product. To check the result, read
          the product with `_fields=categories`. To remove the link, use [Unlink
          a category from a
          product](/reference/v3/products/delete-product-category-link). See
          [Update and delete records](/reference/v3/updates-and-deletes).
