          Deletes one product. A successful delete returns `204` with an empty
          body, and a later request for the product returns `404`. Deleted
          products can't be listed afterwards, so a sync job can't find
          deletions by searching.


          To remove only a link, such as one category, without deleting the
          product, use [Delete a product field value or
          link](/docs/reference/v3/products/delete-product-field). See [Update
          and delete records](/docs/reference/v3/updates-and-deletes).
