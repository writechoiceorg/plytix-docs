          Only that one link is removed. The product, the category, and the product's other categories stay as they are.

          To file the product under a category again, use [Link a category to a product](/reference/v3/products/link-product-category). See [Safely remove categories, assets, or relationships](/docs/guides/safely-removing-categories-assets-or-relationships#remove-a-category-from-a-product) and [Update and delete records](/reference/v3/updates-and-deletes).
