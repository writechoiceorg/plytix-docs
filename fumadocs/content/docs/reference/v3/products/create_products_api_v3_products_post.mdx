          Create a single product.


          The response returns the full created product, including its generated
          `id`, not the ID on its own.


          To create a variant, include `parent_id` and `product_family_id` so
          the new product joins an existing product family hierarchy. See
          [Reconstruct parent/variant
          hierarchies](/docs/guides/reconstructing-parent-variant-hierarchies).


          If the `sku` you send already exists in the account, this returns `409
          Conflict` instead of creating a duplicate.
