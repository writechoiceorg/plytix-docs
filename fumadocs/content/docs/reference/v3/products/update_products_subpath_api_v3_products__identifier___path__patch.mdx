          Update a single field on a product without sending the whole record.

          The `path` is the field name, and the request body is that field's new value on its own, not an object wrapping it. That's a different shape from [Update-Products](/docs/reference/v3/products/update_products_api_v3_products__identifier__patch), which takes a partial product object. Use the root PATCH to change several fields at once, and this one to change exactly one.

          Use the product's Plytix `id` as `identifier`, not its SKU.

          Plytix checks `path` against the fields a product accepts on an update, so a name it doesn't recognize returns `422` instead of creating anything. A successful call returns `200` with the full updated product.

          > **FLAG:** The body shape and the `422` behavior described here are confirmed on other Plytix resources (assets and PIM product lists), not on products specifically. Confirm against a live product before publishing.
