      - content: >-
          Returns one product. You can use the product's `id` or its SKU as the
          identifier: `GET /api/v3/products/BAG-10157` returns the same record
          as a request with the product's ID. An identifier that matches nothing
          returns `404`.


          To return only some fields, use `_fields`, for example
          `_fields=sku&_fields=label`. Without it, you get the full record.


          `data` holds the product object itself, not a list, and the response
          has no `pagination` key.


          `product_relationships` lists only each relationship's ID and label.
          To get the related products, use [Search related
          products](/docs/reference/v3/relatedproducts/search-related-products)
          with `product_id=<id>`.
