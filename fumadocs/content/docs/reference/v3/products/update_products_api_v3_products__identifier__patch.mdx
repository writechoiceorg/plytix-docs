          Update selected fields on a product. Send only the fields you want to change; any field you omit is left untouched.

          The response returns the full updated product, not only the fields you sent. It's the same shape a GET on the product returns, including the `assets`, `categories`, and `relationships` arrays.

          Use the product's Plytix `id` as `identifier`, not its SKU.

          PATCH with a reduced array is the only confirmed way to remove a single category, asset, or relationship link, because the delete-by-subpath endpoint doesn't perform scoped removal. See [Safely remove categories, assets, or relationships](/docs/guides/safely-removing-categories-assets-or-relationships).

          Two constraints to know:

          - Sending `parent_id` and `product_family_id` together returns `422`. A variant inherits family membership from its parent, so omit `product_family_id` when you set `parent_id`.
          - `channel_ids`, `ecatalog_ids`, and `product_data_sheet_ids` require the UEF feature on your account. Without it, including any one of them fails the whole request with `403`, and none of the other fields in that request are applied.
