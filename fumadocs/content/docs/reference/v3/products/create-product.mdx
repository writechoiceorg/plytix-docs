          Create a single product.


          The response returns the created product, including its generated
          `id`, as an object in `data`.


          To create a variant, include `parent_id`. Leave `product_family_id`
          out: the variant takes its family from the parent, and a different
          family returns `422`. See [Rebuild parent and variant
          products](/docs/guides/reconstructing-parent-variant-hierarchies).


          If the `sku` you send already exists in the account, this returns `409
          Conflict` instead of creating a duplicate.
