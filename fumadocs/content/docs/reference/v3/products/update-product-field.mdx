    contents:
      - content: >-
          Changes one custom attribute value and leaves the rest of the product
          as it is. Set `path` to `attributes/<label>` and send the new value on
          its own as the request body: `"2019"`, not `{"value": "2019"}`. A
          successful update returns `204` with an empty body.


          Use this to change a single attribute. [Update a
          product](/reference/v3/products/update-product) replaces the whole
          `attributes` map, so any attribute you leave out of it is removed.


          The value's format depends on the attribute type:


          - Text: a string. `null` removes the value.

          - Decimal: a string, such as `"12.5"`. A JSON number returns `422`.

          - Multi-select: an array of the attribute's configured options, such
          as `["Blue"]`.

          - Media: one asset ID, as a string.

          - Media gallery: an array of asset IDs.


          Completeness and formula attributes are calculated by Plytix, so
          writing to them returns `422`.


          Link collections such as `categories` can't be changed here (`405`).
          Link and unlink records with [Link a record to a
          product](/reference/v3/products/add-product-field) and [Delete a
          product field value or
          link](/reference/v3/products/delete-product-field). See [Update and
          delete records](/reference/v3/updates-and-deletes).
