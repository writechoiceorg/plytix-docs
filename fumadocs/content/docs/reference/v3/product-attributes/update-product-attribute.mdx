      - content: >-
          Changes the settings you send and leaves the others as they are. A
          successful update returns `204` with an empty body. To see the result,
          read the attribute back.


          The body takes the settings of every attribute type. Send only the
          ones that apply to this attribute's type: Plytix checks them against
          the attribute's `type` and rejects the rest. For example, `options`
          applies to dropdown and multi-select attributes, and `character_limit`
          to text attributes.


          Some fields are fixed once the attribute exists:


          - `label` can't be changed. Sending it returns `422`. Products keep
          their values under the same `attributes.<label>` key.

          - `type` can't be changed.

          - `name` can be changed. Renaming doesn't change `label`.


          Group membership and product family membership aren't changed here. To
          add the attribute to a group, use [Link an attribute to a
          group](/reference/v3/product-attributes/link-product-attribute-group).
          To link the attribute to a product family, use [Link an attribute to a
          product
          family](/reference/v3/family-attributes/add-attribute-to-family).


          See [Update and delete records](/reference/v3/updates-and-deletes) for
          how PATCH works across the V3 API.
