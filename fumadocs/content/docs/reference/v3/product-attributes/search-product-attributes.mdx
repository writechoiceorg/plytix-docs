      - content: >-
          Returns attribute definitions, one page at a time. Each record holds
          the attribute's `id`, `name`, `label`, `type`, and the settings of
          that type, such as a dropdown's `options`.


          Use it to find the `label` to use as a key in a product's `attributes`
          map, or to find attributes of one type, for example
          `type=CompletenessAttribute`. Products store custom attribute values
          keyed by `label`, not by the display `name`.


          The `type` field tells you which shape a record has. The response
          schema below has one tab per type.
