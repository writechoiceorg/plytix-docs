title: Link an attribute to a group
full: true
_openapi:

    - ./openapi.json
  method: POST
  path: "/api/v3/product-attributes/{identifier}/groups"
  webhook: false
  toc: []
  structuredData:
    headings: []
    contents:
      - content: |-
          Adds the attribute to one existing attribute group. Send the group's ID as `{"id": "<group_id>"}`. A successful link returns `201` with the group's ID.

          Send one group per request. If the attribute is already in the group, the request returns `409`.

          Attributes and groups don't accept membership lists on create or update (`422`), so this is how to put an attribute in a group. To check the result, use [Get a product attribute field](/reference/v3/product-attributes/get-product-attribute-field) with `groups`. To take the attribute out of the group, use [Unlink an attribute from a group](/reference/v3/product-attributes/delete-product-attribute-group-link).
