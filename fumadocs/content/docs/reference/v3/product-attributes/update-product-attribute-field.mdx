      - content: >-
          Changes one setting of an attribute and leaves the others as they are.
          Set `path` to the setting and send the new value on its own as the
          request body, not wrapped in an object. For example, to rename an
          attribute, set `path` to `name` and send `"Collection name"`. The
          attribute's `label` and `type` can't be changed.


          To change several settings in one request, such as a dropdown's
          `options`, use [Update a product
          attribute](/reference/v3/product-attributes/update-product-attribute),
          which lists the settings of each attribute type.
