      - content: >-
          Creates one product category and returns it, including its new `id`.
          Only `name` is required, and the body accepts only `name` and
          `parent_id`.


          Without `parent_id`, the category is created at the top of the tree.
          To create a subcategory, set `parent_id` to the ID of an existing
          category. The new category's `path` then lists every name above it,
          and the parent's `n_children` goes up by one.


          Plytix generates the `slug` from the name, for example `kitchen-sinks`
          for "Kitchen Sinks".


          A successful create returns `201`. The response holds fewer fields
          than [Get a product
          category](/reference/v3/product-categories/get-product-category): it
          leaves out `created` and `modified`, and on a top-level category,
          `parent_id`.


          Re-creating a category that already exists, with the same `name` and
          `parent_id`, returns `409`.


          Creating a category doesn't file any products under it. To add a
          product to a category, use [Link a record to a
          product](/reference/v3/products/add-product-field). See [The Plytix
          data model](/docs/guides/data-model#product-categories).
