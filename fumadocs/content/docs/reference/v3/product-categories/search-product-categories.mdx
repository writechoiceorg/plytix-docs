      - content: >-
          Returns the product categories in your account, one page at a time.
          With no filters, it returns every category at every level of the tree
          in one flat list.


          Each category carries its place in the tree:


          - `parent_id`: the ID of the category above it. In search results, a
          top-level category has no `parent_id` key.

          - `path`: the names from the top of the tree down to this category,
          for example `["Sample Categories", "Drinkware"]`.

          - `n_children`: how many categories sit directly below it.


          Names can repeat in different branches, so check `path` to pick the
          right one.


          To find the products filed under a category, search products instead,
          with a filter such as `categories.name=Drinkware`. See [Search
          products](/reference/v3/products/search-products).


          Results come back 25 per page by default. Follow
          `pagination.next_page` to get the next page, and change its `http://`
          to `https://` first.


          Related pages:


          - [Filtering and search](/reference/v3/filtering-and-search)

          - [Pagination](/reference/v3/pagination)

          - [The Plytix data model](/docs/guides/data-model#product-categories)
