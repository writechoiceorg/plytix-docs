      - content: >-
          Returns the value of one field of a product category, without the rest
          of the record. Set `path` to the field, for example `name` or `path`.


          On a subcategory, `parent` returns the parent category as a full
          object, so you don't need a second request.


          A field the category doesn't have returns `400`, and the message lists
          the fields you can ask for. A category ID that doesn't exist returns
          `404`.
