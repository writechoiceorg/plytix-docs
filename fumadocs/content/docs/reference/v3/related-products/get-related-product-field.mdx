          Fetch a single field from one product-to-product link, such as
          `quantity`, instead of the whole record.


          > **Warning:** This resolves the link through the same lookup as [Get
          a related
          product](/reference/v3/related-products/get-related-product), which
          can't find links that do exist, so expect the same `404` here. Read a
          link's fields through [Search related
          products](/reference/v3/related-products/search-related-products) with
          `?product_id=<id>` and `_fields` instead.


          All path segments take Plytix IDs, not SKUs.
