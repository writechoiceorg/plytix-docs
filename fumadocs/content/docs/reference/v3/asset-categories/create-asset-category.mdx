    contents:
      - content: >-
          Creates one asset category and returns it, including its new `id`.
          Only `name` is required.


          To create a subcategory, set `parent_id` to the ID of the parent asset
          category. Leave it out to create a top-level category.


          A successful create returns `201`. `data` holds the new category's
          `id`, `name`, and `order`, plus `parent_id` for a subcategory. To get
          `created` and `modified`, read the category back.


          Re-creating an asset category that already exists, with the same
          `name` and `parent_id`, returns `409`.
