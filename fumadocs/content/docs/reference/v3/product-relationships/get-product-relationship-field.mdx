          Fetch a single field from one of a product's relationship links, such as `relationship_label`, instead of the whole record.

          `path` accepts the link record's own fields: `_id`, `product_id`, `account_id`, `relationship_id`, and `relationship_label`. Any other name returns `400` with a `ValueError` listing those five. `account_id` is readable here even though no other response on this resource returns it.

          A link holds only three visible fields, so [Get a product relationship](/reference/v3/product-relationships/get-product-relationship) usually gets you the same thing in one call.
