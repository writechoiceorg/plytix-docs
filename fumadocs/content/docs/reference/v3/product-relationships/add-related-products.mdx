  structuredData:
    headings: []
    contents:
      - content: >-
          Link one or more products to this product under a relationship type.
          Returns `201` with the created link.


          Both body fields are required: `{"relationship_id": "<id>",
          "related_products": [{"product_id": "<id>", "quantity": 3},
          {"product_id": "<id>", "quantity": 7}]}`. `relationship_id` is the ID
          of the relationship type, from [Search
          relationships](/reference/v3/relationships/search-relationships).
          Inside `related_products`, the field is `product_id`, passing `id`
          returns `422` naming both the missing field and the extra one.
          `quantity` is optional and defaults to `1`.


          The response is richer than this resource's `GET` views: its
          `related_products` entries carry `related_product_id` and
          `last_modified` per link, so it tells you which products ended up on
          the other end. Keep that response, or read the links back with [Search
          related
          products](/reference/v3/related-products/search-related-products)
          using `?product_id=<id>`.
