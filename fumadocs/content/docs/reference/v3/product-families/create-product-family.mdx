      - content: >-
          Creates a product family and returns it, including its new `id`.
          `name` is the only field in the body.


          Family names are unique in your account. If a family with that name
          already exists, the request returns `409` and creates nothing.


          To add attributes to the family, link them after it exists with [Link
          an attribute to a product
          family](/reference/v3/family-attributes/add-attribute-to-family). Each
          link sets the attribute's inheritance `level`.


          See [The Plytix data
          model](/docs/guides/data-model#product-families-and-variants) for how
          levels work, and [Update and delete
          records](/reference/v3/updates-and-deletes).
