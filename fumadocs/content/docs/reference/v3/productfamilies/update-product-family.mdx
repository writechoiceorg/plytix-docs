          Changes a product family's name. `name` is the only field you can
          change here. A successful update returns `204` with an empty body.


          Attribute fields such as `attributes` aren't accepted and return
          `422`, because changing which attributes belong to a family affects
          every product in it. Manage a family's attributes with [Link an
          attribute to a product
          family](/docs/reference/v3/familyattributes/create-family-attribute)
          and [Unlink an attribute from a product
          family](/docs/reference/v3/familyattributes/delete-family-attribute).


          See [Update and delete
          records](/docs/reference/v3/updates-and-deletes).
