      - content: >-
          Creates a product family and returns it, including its new `id`. Only
          `name` is required.


          Family names are unique in your account. If a family with that name
          already exists, the request returns `409` and creates nothing.


          To link attributes in the same request, list them in `attributes`.
          Each attribute is linked at `no_level`, so its values don't pass down
          from parents to variants. A new family can already have some
          attributes linked, so `total_attributes` can be higher than the number
          you send. To add attributes after the family exists, use [Link an
          attribute to a product
          family](/docs/reference/v3/familyattributes/create-family-attribute).


          Refer to attributes in one of two forms: their IDs, or objects with
          the attribute's `label` and, optionally, its `id`. Use the same form
          in every attribute array of the request. Mixing forms returns `422`.


          `parent_attributes` and `variant_attributes` link attributes at
          `parent_level` and `variant_level`. On some accounts these fields
          return `403` with "Automatic inheritance is not available for this
          account", and nothing is created. If you get this response, ask your
          Plytix contact whether inheritance is available for your account.


          See [The Plytix data
          model](/docs/guides/data-model#product-families-and-variants) for how
          levels work, and [Update and delete
          records](/docs/reference/v3/updates-and-deletes).
