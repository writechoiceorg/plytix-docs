      - content: >-
          Returns the asset lists in your account, one page at a time. An asset
          list is a saved selection of assets. Each list has a `type`:


          - `Smart`: the list stores a `query`, and its members are the assets
          that match it.

          - `Static`: membership is stored on each asset. Plytix generates the
          list's `query`, which points at the list's own ID.


          The records describe the lists, not the assets in them.


          `_fields` doesn't accept `type` here and returns `400`. To see a
          list's type, use [Get an asset
          list](/reference/v3/asset-lists/get-asset-list).


          Results come back 25 per page by default. Follow
          `pagination.next_page` to get the next page, and change its `http://`
          to `https://` first.


          Related pages:


          - [Filtering and search](/reference/v3/filtering-and-search)

          - [Pagination](/reference/v3/pagination)
