## What it is

Plytix is a PIM (Product Information Management) platform, and the API lets you connect your own systems (an ERP, a storefront, an internal tool) to your Plytix account, so you can manage products, assets, and other PIM data programmatically instead of only through the dashboard.

This documentation is for integration engineers who connect Plytix to an ERP, storefront, or marketplace, automation builders who script repetitive tasks such as bulk exports and data quality checks, and partner developers who build products that integrate with Plytix for multiple customers.

It is separate from the [Plytix Help Center](https://help.plytix.com/en), which covers using the Plytix dashboard itself (managing products by hand, configuring channels, account administration).

## API versions

This documentation covers both versions of the Plytix API. V3 is the current API and the one to use for new integrations. V1/V2 remains available for existing integrations, and a few of its operations have no V3 equivalent yet.
