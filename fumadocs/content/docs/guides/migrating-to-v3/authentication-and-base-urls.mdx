V1/V2 share one authentication flow, and V3 is moving to a new token-based model whose details aren't published yet. This page lists the base URLs, path prefixes, and authentication details for each. It's part of the reference set for [Migrating to V3](/docs/guides/migrating-to-v3).

## V1/V2 base URL and authentication

V1/V2 share one authentication flow. You exchange your API credentials for a bearer token, then send that token with every request to either version.

| Item | Value |
|---|---|
| API base URL | `https://pim.plytix.com` |
| API path prefixes | `/api/v1`, `/api/v2` |
| Token endpoint | `POST https://auth.plytix.com/auth/api/get-token` |
| Credentials in the token request | `api_key` and `api_password`, in a JSON body |
| Header on every API request | `Authorization: Bearer <token>` |

### API credentials and bearer tokens

Your API credentials and your bearer token do different jobs. The credentials identify you once, at the token endpoint. The token authenticates every API request after that.

| | API credentials | Bearer token |
|---|---|---|
| What it is | Your API Key and password | A short-lived access token, returned as `access_token` |
| Where it comes from | An account administrator issues them from the **API** tab in the account's Admin section | The token endpoint, in exchange for your credentials |
| Where you send it | Only in the body of the token request | In the `Authorization` header of every V1/V2 request |

A token expires after 15 minutes. When it expires, or the API can't verify it, requests return `401`, and you request a new token with the same credentials. See [Authentication](/docs/reference/legacy/token-authentication) for the full token request, response, and errors.

## V3 base URL and authentication

V3 runs on the same base URL as V1/V2, under its own path prefix:

| Item | Value |
|---|---|
| API base URL | `https://pim.plytix.com` |
| API path prefix | `/api/v3` |

{/* FLAG (open):
  The V3 base URL `https://pim.plytix.com/api/v3` isn't confirmed on production. Live testing confirmed V3 only on `pim.dev.plytix.com` with a dev token. On the production host, V3 returned `401` to a dev token. Re-test with a production credential before relying on this table for V3.
*/}

<Callout type="info" title="V3 authentication is changing">
  V3 is moving to a new token-based authentication model, and its details aren't published yet. See [V3 authentication](/docs/reference/v3/authentication) for the model once it's documented.
</Callout>
