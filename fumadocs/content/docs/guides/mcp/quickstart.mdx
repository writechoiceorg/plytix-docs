Add the Plytix MCP as a remote MCP server in your AI application, then sign in to Plytix with OAuth. Follow the instructions for Claude, ChatGPT, or Microsoft Copilot below, then verify the connection.

## Prerequisites

Before you start, make sure you have the following:

- Plytix MCP access turned on for your Plytix account. To request it, contact your account manager.
- An AI application that supports remote MCP servers and OAuth sign-in, such as Claude, ChatGPT, or Microsoft Copilot. Your subscription plan and workspace settings determine whether you can add a custom connection. A workspace administrator may need to add or approve the connection first. Check the requirements for your application in the tabs below.
- A Plytix user account to sign in with. Your assistant works within that user's Plytix plan and permissions, so it can't make changes your Plytix user isn't allowed to make.

You'll need the following connection details:

| Setting | Value |
|---|---|
| Server URL | `https://pim.plytix.com/mcp` |
| Authentication | OAuth |

You don't need V3 API beta access or a V3 access token to use the Plytix MCP. Sign in to Plytix with OAuth when your AI application prompts you.

## Add the Plytix MCP to your AI application

Select your AI application and follow the steps to add the server, authorize the connection, and enable it in a conversation.

  <Tab value="Claude">
    Custom connectors work in Claude on the web and in Claude Desktop, on every plan. On the Free plan, you can add one custom connector.

    **On a Team or Enterprise plan**, the connector is set up once for the whole organization, then each member signs in.

    **Organization setup:** An owner or another user with connector-management permissions adds Plytix. On Team, Owners and Primary Owners can add it. On Enterprise, Owners, Primary Owners, and custom roles with Manage access to Libraries can add it.

    1. **Open** **Organization settings** > **Connectors** in Claude.
    2. **Click** **Add**, hover over **Custom**, and select **Web**.
    3. **Enter** `Plytix` as the name and `https://pim.plytix.com/mcp` as the server URL, then click **Continue**.
    4. **Review** the authentication settings that Claude detects for the server, then click **Continue**.
    5. **Select** **Sign in now** under **Authentication**, keep the detected **OAuth client** setting, and click **Add**.

    **Member sign-in:** Each member connects with their own Plytix account.

    1. **Open** **Customize** > **Connectors**, select **Plytix**, and click **Connect**.
    2. **Sign in** to your own Plytix account in the window that opens. Review the access that Claude requests, then approve it.
    3. **Turn on** the connector in a conversation: click the **+** button in the lower left of the chat, click **Connectors**, and turn on the **Plytix** toggle.

    **On a Free, Pro, or Max plan**, add the connector yourself:

    1. **Open** **Customize** > **Connectors** in Claude.
    2. **Click** **+ Add**, then **Add custom connector**.
    3. **Enter** `Plytix` as the name and `https://pim.plytix.com/mcp` as the server URL, then click **Continue**.
    4. **Review** the authentication settings that Claude detects for the server, then click **Continue**.
    5. **Select** **Sign in now** under **Authentication**, keep the detected **OAuth client** setting, and click **Add**.
    6. **Sign in** to Plytix in the window that opens. Review the access that Claude requests, then approve it.
    7. **Turn on** the connector in a conversation: click the **+** button in the lower left of the chat, click **Connectors**, and turn on the **Plytix** toggle.

    Claude asks for your approval before it runs a tool. Select **Allow always** only for tools you trust to run without review, such as tools that only read data. To keep a tool from running in a conversation, turn it off in the **Search and tools** menu.

    To remove the connection, open **Customize** > **Connectors** and find **Plytix**. Select **Remove**, or open its three-dot menu and select the removal option. Complete any confirmation prompts. On a Team or Enterprise plan, owners remove the organization's connector in **Organization settings** > **Connectors**.

    For plan and workspace requirements, see [Claude's guide to custom connectors](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).

  <Tab value="ChatGPT">
    You add custom MCP servers in ChatGPT on the web. Whether you can add one depends on your ChatGPT plan and workspace: workspace permissions and security restrictions apply, and on some workspace plans only admins and owners can add a custom MCP server. Check your plan in OpenAI's guide linked at the end of this tab.

    1. **Go** to [chatgpt.com/plugins](https://chatgpt.com/plugins), select the plus button, then select **Add custom MCP server**.
    2. **Enter** `Plytix` as the name. You can also add a description.
    3. **Enter** `https://pim.plytix.com/mcp` as the server URL under **Connection**.
    4. **Select** **OAuth** as the authentication method.
    5. **Review** the risk warning, then select **I understand and want to continue**.
    6. **Select** **Create as a plugin**.
    7. **Install** the Plytix plugin. You'll find it in your personal plugins, or in the workspace where you created it.
    8. **Sign in** to Plytix when ChatGPT asks you to. Review the access that ChatGPT requests, then approve it.
    9. **Use** the plugin in a conversation: type `@` in the prompt box and select **Plytix**.

    ChatGPT asks you to confirm write actions before they run, and you can turn individual tools on or off on the plugin's details page in your settings. Review each tool request before approving it. Choose to remember an approval only if you trust the tool to make further changes without another review. A remembered approval applies to that tool for the rest of the conversation, and a new conversation asks for confirmation again.

    After a Plytix MCP release, open the plugin's details page and refresh it, so ChatGPT picks up new and changed tools.

    To remove the connection, go to **Plugins** > **Personal**, open the three-dot menu on the **Plytix** plugin, and select **Uninstall**.

    For plan, workspace, and authentication details, see [OpenAI's guide to adding a custom MCP server](https://developers.openai.com/api/docs/guides/custom-mcp-server).
  </Tab>
  <Tab value="Microsoft Copilot">
    You connect the Plytix MCP to Microsoft Copilot through Copilot Studio. You add Plytix as a tool to a Copilot Studio agent, then make the agent available in Microsoft 365 Copilot and Teams. Publishing an agent requires a Copilot Studio subscription, and the agent must use generative orchestration, which MCP tools require. Your organization's data policies and admin settings can limit which tools and channels you can use.

    **Add Plytix to your agent:**

    1. **Open** your agent in Copilot Studio and go to its **Tools** page.
    2. **Select** **Add a tool**, then **New tool**.
    3. **Select** **Model Context Protocol** in the **Create new** section.
    4. **Enter** `Plytix` as the **Server name**, a short **Server description**, and `https://pim.plytix.com/mcp` as the **Server URL**.
    5. **Select** **OAuth 2.0** as the authentication type and **Dynamic discovery** as the type, then select **Create**.
    6. **Select** **Next**, then select **Create a new connection** in the **Add tool** dialog. Sign in to Plytix when prompted, review the access requested, then approve it.
    7. **Select** **Add to agent**.

    **Make the agent available in Microsoft 365 Copilot and Teams:**

    1. **Select** **Publish** in your agent, then confirm.
    2. **Select** **Channels** on the top menu bar, then select the **Microsoft 365 and Microsoft Teams** tile.
    3. **Check** that **Make agent available in Microsoft Copilot** is selected, then select **Add channel**.
    4. **Select** **See agent in Teams**, then **Add**, to install the agent in Teams and Microsoft 365 Copilot.

    By default, each person who uses the agent connects with their own Plytix account. The first time the agent calls a Plytix tool, it shows a connection card. Select **Connect** and sign in to Plytix in the window that opens.

    All Plytix tools are turned on when you add the server. To choose which tools the agent can use, select **Plytix** on the agent's **Tools** page, turn off **Allow all**, and turn on the tools you want. Then select **Save** and **Publish**. After you publish, tool changes can take up to 24 hours to reach the agent.

    To remove the connection, go to the agent's **Tools** page, hover over **Plytix**, open its three-dot menu, and select **Delete**. Confirm the deletion, then publish the agent again.

    For licensing, authentication, and admin requirements, see [Microsoft's guide to connecting an agent to an MCP server](https://learn.microsoft.com/en-us/microsoft-copilot-studio/mcp-add-existing-server-to-agent).

## Verify the connection

Follow the steps below to confirm that your AI application found the Plytix tools and can read your account.

1. **Check** the tool list in your AI application's connection settings to see which tools were discovered. Claude shows them in the connector's settings, ChatGPT on the plugin's details page, and Copilot Studio on the Plytix tool's settings page.
2. **Run** a small read that you can check yourself, the first prompt in [Example workflows](/mcp/example-workflows#find-a-product). Replace `YOUR-SKU` with a SKU that exists in your account, then ask:

   ```text
   Using Plytix, find the product with SKU YOUR-SKU and show its SKU, name, and description. Don't change anything.
   ```

   Check that your assistant called a Plytix tool, then compare the answer against the product in Plytix. If the values match, the connection works and your account is reachable. If the answer has no specifics, your assistant probably answered without calling Plytix. See [Troubleshooting](/mcp/troubleshooting).

An answer that only describes the available capabilities doesn't confirm a successful connection, so always finish with the product lookup.
