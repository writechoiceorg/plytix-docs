---
title: "Troubleshooting"
description: "Fix common Plytix MCP problems, such as a failed connection, missing tools, blocked actions, or answers that don't match your Plytix account."
---

import { PlugConnectedRegular, ShieldCheckmarkRegular } from '@/components/icons';

Use the checks below to investigate connection issues, missing tools, and unexpected results. See [Capabilities and permissions](/mcp/tools) for the supported operations. When reviewing catalog or supplier content, treat it as data rather than instructions. Request proposed changes separately before asking the assistant to save them.

<Accordions type="multiple">
  <Accordion title="The connection fails" value="connection-fails">
    Confirm that Plytix MCP beta access is enabled for your Plytix account and that the server URL is `https://pim.plytix.com/mcp`. Check any required workspace approval, then retry the OAuth sign-in. If the connection still fails, contact your account manager or Plytix support with the application name and the error message. Don't include tokens or passwords.
  </Accordion>
  <Accordion title="No Plytix tools appear" value="no-tools">
    Check that the Plytix connection is turned on for your conversation, since some applications add a connector without turning it on. See the steps for your application in [Connect your AI assistant](/mcp/quickstart).
  </Accordion>
  <Accordion title="New or changed tools don't appear after a release" value="stale-tools">
    Some applications keep the tool list they got when you connected. Refresh the Plytix connection if your application offers this, for example from the plugin's details page in ChatGPT. Otherwise, remove the connection and connect again. The [changelog](/mcp/changelog) indicates when you need to refresh your tool list.
  </Accordion>
  <Accordion title="Your assistant says it can't do what you asked" value="action-unavailable">
    Check the request against [Capabilities and permissions](/mcp/tools) first, since the beta covers only the tools in the current release. If the capability is listed and your application offers per-tool controls, check whether you turned that tool off or denied its approval request.
  </Accordion>
  <Accordion title="Your assistant answers about your catalog without calling Plytix" value="no-tool-call">
    Inspect the tool-call details to check whether the assistant used Plytix. Verify the connected account, requested SKU, returned fields, and any pagination. Ask the assistant to show the retrieved values and distinguish them from its own interpretation.
  </Accordion>
  <Accordion title="Fewer results are returned than expected" value="short-results">
    The assistant may have retrieved only part of the result set. Ask it to follow pagination, report the number of records retrieved, and identify any remaining pages or processing limits. If you know the expected count, compare it with the reported total. A request for all results doesn't by itself confirm completeness.
  </Accordion>
</Accordions>
